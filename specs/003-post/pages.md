## 三、功能区域

### 3.1 搜索区域

| 字段 | 组件类型 | 说明 |
|------|---------|------|
| 岗位编码 | Input | 模糊匹配 |
| 岗位名称 | Input | 模糊匹配 |
| 状态 | Select | 0-正常/1-停用 |

### 3.2 工具栏

| 按钮 | 权限 | 说明 |
|------|------|------|
| 新增 | `system:post:add` | 打开新增对话框 |
| 修改 | `system:post:edit` | 修改选中岗位（单选） |
| 删除 | `system:post:remove` | 删除选中岗位（支持批量） |
| 导出 | `system:post:export` | 导出当前查询结果 |

### 3.3 数据表格

| 列名 | 字段 | 宽度 | 说明 |
|------|------|------|------|
| 选择 | selection | 50 | 多选框 |
| 岗位编码 | postCode | 120 | - |
| 岗位名称 | postName | 120 | - |
| 岗位排序 | postSort | 80 | - |
| 状态 | status | 80 | 开关组件 |
| 创建时间 | createTime | 160 | 格式化显示 |
| 操作 | - | 150 | 操作按钮组 |

## 四、新增/编辑对话框

**表单字段：**

| 字段 | 组件类型 | 必填 | 验证规则 |
|------|---------|------|---------|
| 岗位编码 | Input | 是 | 64 字符内 |
| 岗位名称 | Input | 是 | 50 字符内 |
| 显示顺序 | InputNumber | 是 | - |
| 状态 | Radio | 否 | 0-正常/1-停用 |
| 备注 | Input | 否 | 500 字符 |
