# 003-岗位管理 - 功能规格

**模块编号：** 003  
**模块名称：** 岗位管理 (Post Management)  
**所属模块：** 系统管理  
**版本：** 3.9.1  
**最后更新：** 2026-03-12

---

## 一、功能概述

岗位管理用于配置系统用户所属的职务。岗位与用户是多对多关系，一个用户可以担任多个岗位，一个岗位也可以有多个用户。

### 1.1 核心功能

- **岗位 CRUD**：新增、查询、修改、删除岗位
- **岗位排序**：自定义岗位显示顺序
- **状态管理**：启用/停用岗位
- **导入导出**：支持 Excel 批量导入导出
- **用户关联**：查询岗位下的用户列表

### 1.2 业务规则

1. **岗位编码唯一性**：岗位编码（postCode）在全系统必须唯一
2. **岗位名称唯一性**：岗位名称（postName）在全系统必须唯一
3. **岗位排序**：数字越小越靠前
4. **停用约束**：岗位被用户使用时建议不停用（无强制约束）

## 二、功能详细设计

### 2.1 岗位列表查询

**功能描述：** 分页查询岗位列表

**查询条件：**
- 岗位编码（模糊匹配）
- 岗位名称（模糊匹配）
- 岗位状态（0-正常 / 1-停用）

**列表字段：**
- 岗位序号、岗位编码、岗位名称
- 岗位排序、状态、创建时间
- 操作列

**权限标识：** `system:post:list`

### 2.2 新增岗位

**功能描述：** 创建新的岗位

**必填字段：**
- 岗位编码（唯一）
- 岗位名称（唯一）
- 显示顺序

**可选字段：**
- 状态（默认正常）
- 备注

**业务校验：**
1. 校验岗位编码是否已存在
2. 校验岗位名称是否已存在

**权限标识：** `system:post:add`

### 2.3 修改岗位

**功能描述：** 修改岗位信息

**可修改字段：** 同新增岗位

**业务校验：**
1. 校验岗位编码是否已存在（排除自身）
2. 校验岗位名称是否已存在（排除自身）

**权限标识：** `system:post:edit`

### 2.4 删除岗位

**功能描述：** 删除一个或多个岗位

**业务规则：**
1. 支持批量删除
2. 删除前建议检查是否有用户使用（无强制约束）

**权限标识：** `system:post:remove`

### 2.5 导出岗位

**功能描述：** 导出岗位列表为 Excel 文件

**权限标识：** `system:post:export`

### 2.6 岗位选择框

**功能描述：** 获取所有正常岗位列表（用于用户管理模块）

**接口：** `GET /system/post/optionselect`

**权限：** 无（登录即可）

## 三、权限设计

### 3.1 权限标识清单

| 权限标识 | 权限名称 | 说明 |
|---------|---------|------|
| `system:post:list` | 岗位查询 | 查询岗位列表 |
| `system:post:query` | 岗位详情 | 查询岗位详细信息 |
| `system:post:add` | 岗位新增 | 新增岗位 |
| `system:post:edit` | 岗位修改 | 修改岗位信息 |
| `system:post:remove` | 岗位删除 | 删除岗位 |
| `system:post:export` | 导出岗位 | 导出岗位数据 |

## 八、注意事项

1. **编码规范**：岗位编码建议使用大写字母 + 数字组合
2. **排序维护**：新增岗位时注意排序值，避免重复
3. **删除检查**：删除前建议检查是否有用户使用
