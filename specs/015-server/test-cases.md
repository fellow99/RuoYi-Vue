## 一、测试概述

### 1.1 测试范围

本测试覆盖服务器监控模块的全链路功能，包括：

- **服务器状态查看**：CPU、内存、JVM、系统信息、磁盘状态的全面监控展示
- **数据采集与格式化**：通过 OSHI 库实时采集服务器硬件信息并转换为人类可读格式
- **阈值告警**：内存使用率和磁盘使用率超过 80% 时的红色视觉警告
- **权限控制**：基于 `monitor:server:list` 权限的页面级和 API 级访问控制
- **异常处理**：API 请求失败、超时、网络异常、空数据等边界场景

### 1.2 测试类型

| 测试类型 | 占比 | 说明 |
|---------|------|------|
| 功能测试 | 41% | 核心数据采集展示、格式化、阈值告警 |
| 界面测试 | 24% | 页面卡片布局、栅格响应式、条件渲染、图标 |
| 权限测试 | 10% | 权限控制页面访问和 API 调用 |
| 异常测试 | 24% | API失败、超时、空数据、OSHI异常 |

### 1.3 测试环境

| 项目 | 配置说明 |
|------|---------|
| 操作系统 | Linux (CentOS 7+ / Ubuntu 18.04+) / Windows Server 2016+ / Docker |

| 分辨率 | 1920×1080 / 1366×768 / 375×812 |
