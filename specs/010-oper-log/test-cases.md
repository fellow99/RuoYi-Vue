# 010-操作日志 - 测试用例

**模块编号：** 010  
**模块名称：** 操作日志  
**版本：** 3.9.1  
**最后更新：** 2026-05-04

---

## 一、测试概述

### 1.1 测试范围

本模块测试覆盖操作日志的查询、详情查看、删除、清空、导出以及权限控制等全部功能。包括：
- 操作日志列表的分页查询与多条件筛选
- 6个查询条件的独立与组合筛选（操作地址、系统模块、操作人员、操作类型、操作状态、操作时间）
- 3个排序字段的升序/降序切换
- 操作日志详细弹窗的信息展示（基本信息、操作人员、请求信息、请求参数、返回参数、异常信息）
- 批量删除与单个删除
- 一键清空所有日志
- 导出查询结果为 Excel 文件
- 前端按钮/后端 API 的权限校验
- 边界值、异常输入、并发操作的容错处理

### 1.2 测试类型

| 测试类型 | 占比 | 说明 |
|---------|------|------|
| 功能测试 | 50% | 核心CRUD及业务逻辑 |
| 界面测试 | 15% | 页面布局、交互、响应式 |
| 权限测试 | 15% | 按钮权限、接口访问控制 |
| 异常测试 | 20% | 边界条件、异常处理、并发 |

### 1.3 测试环境

- 浏览器：Chrome 90+, Firefox 88+
- 分辨率：1920×1080 / 1366×768
- 用户角色：管理员（拥有全部权限）、普通用户（无权限）
