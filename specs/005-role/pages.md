## 三、新增/编辑对话框

**表单字段：**

| 字段 | 组件类型 | 必填 | 验证规则 |
|------|---------|------|---------|
| 角色名称 | Input | 是 | 30 字符内 |
| 角色权限 | Input | 是 | 100 字符内 |
| 显示顺序 | InputNumber | 是 | - |
| 数据范围 | Select | 否 | 1-全部/2-自定义/3-本部门/4-本部门及以下/5-仅本人 |
| 菜单关联显示 | Switch | 否 | 父子是否关联 |
| 状态 | Radio | 否 | 0-正常/1-停用 |
| 菜单权限 | Tree | 否 | 树形选择 |
| 备注 | Input | 否 | 500 字符 |

**数据范围联动：**
- 选择"自定义数据权限"时显示部门树选择

## 十、交互细节

### 10.1 状态切换

- 使用 `el-switch` 组件
- 切换时检查是否为超级管理员
- 超级管理员不可停用

### 10.2 菜单权限选择

- 使用树形选择器
- 支持父子关联
- 超级管理员默认全选

### 10.3 数据权限联动

- 选择"自定义"时显示部门树
- 其他选项隐藏部门选择

### 10.4 用户授权

- 选项卡切换已分配/未分配
- 支持批量操作
- 实时刷新列表

---

## 十一、注意事项

1. **超级管理员保护**：不允许修改、停用、删除
2. **权限缓存**：修改后清除相关用户缓存
3. **数据权限**：自定义数据权限需选择部门
4. **删除检查**：删除前检查是否有用户使用
