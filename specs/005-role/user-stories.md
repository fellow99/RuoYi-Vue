## 1. 角色管理功能

### US-005-001 角色列表查询

**作为** 系统管理员  
**我想要** 查看角色列表  
**以便于** 了解系统中所有角色

**验收标准**：
- [ ] 可以查看角色列表
- [ ] 支持按角色名称、权限字符模糊搜索
- [ ] 支持按状态筛选
- [ ] 支持分页展示

**优先级**：高  
**故事点**：1

---

### US-005-002 新增角色

**作为** 系统管理员  
**我想要** 新增角色  
**以便于** 创建新的角色类型

**验收标准**：
- [ ] 必须填写角色名称（全系统唯一）
- [ ] 必须填写角色权限字符（全系统唯一）
- [ ] 必须填写显示顺序
- [ ] 可以设置数据范围
- [ ] 角色名称不能重复
- [ ] 角色权限字符不能重复

**优先级**：高  
**故事点**：3

---

### US-005-003 修改角色

**作为** 系统管理员  
**我想要** 修改角色信息  
**以便于** 更新角色的配置

**验收标准**：
- [ ] 可以修改角色名称
- [ ] 可以修改角色权限字符
- [ ] 可以修改显示顺序
- [ ] 可以修改数据范围
- [ ] 不能修改管理员角色（roleId=1）

**优先级**：高  
**故事点**：2

---

### US-005-004 删除角色

**作为** 系统管理员  
**我想要** 删除角色  
**以便于** 移除不需要的角色

**验收标准**：
- [ ] 角色已分配给用户时不允许删除
- [ ] 不能删除管理员角色
- [ ] 删除后解除与用户的关联

**优先级**：中  
**故事点**：2

---

### US-005-005 修改角色状态

**作为** 系统管理员  
**我想要** 启用或停用角色  
**以便于** 控制角色的有效性

**验收标准**：
- [ ] 可以快速切换角色状态
- [ ] 停用的角色不能分配给用户

**优先级**：中  
**故事点**：1

---

## 2. 角色权限配置

### US-005-006 分配菜单权限

**作为** 系统管理员  
**我想要** 为角色分配菜单权限  
**以便于** 控制角色的功能访问

**验收标准**：
- [ ] 可以查看当前角色的菜单权限
- [ ] 可以选择菜单（树形展示）
- [ ] 选择父菜单时自动包含子菜单
- [ ] 可以分配按钮权限
- [ ] 保存后立即生效

**优先级**：高  
**故事点**：5

---

### US-005-007 配置数据权限

**作为** 系统管理员  
**我想要** 配置角色的数据范围  
**以便于** 控制角色能访问的数据

**验收标准**：
- [ ] 可以选择数据范围类型
- [ ] 全部数据权限：可查看所有数据
- [ ] 自定义数据权限：可查看指定部门数据
- [ ] 本部门数据权限：可查看本部门数据
- [ ] 本部门及以下：可查看本部门及子部门数据
- [ ] 仅本人数据：只能查看自己的数据

**优先级**：高  
**故事点**：5

---

**优先级**：高
