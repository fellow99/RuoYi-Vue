## 📖 文档说明

本文档为 RuoYi-Vue 框架 19 个功能模块的测试用例索引，每个模块的测试用例均基于对应的 `user-stories.md`（用户故事）、`pages.md`（前端页面规格）、`spec.md`（功能规格）和 `api.md`（接口规格）生成，覆盖功能测试、界面测试、权限测试和异常测试四大类。

### 测试用例文档结构

每个模块的 `test-cases.md` 包含以下章节：

| 章节 | 内容 |
|------|------|
| 一、测试概述 | 测试范围、类型分布、测试环境 |
| 二、功能测试用例 | 核心 CRUD 及业务逻辑测试 |
| 三、界面测试用例 | 页面布局、组件渲染、交互测试 |
| 四、权限测试用例 | 按钮权限、数据权限测试 |
| 五、异常测试用例 | 边界条件、异常处理、并发操作测试 |
| 六、测试用例统计 | 按类型和优先级汇总统计 |

## 📋 模块测试用例详情

### 001-用户管理 (77 条)

**覆盖范围：**
- 用户列表查询、新增、修改、删除、导出、导入
- 用户角色分配、部门分配、重置密码
- 用户状态切换、头像上传
- 个人中心信息修改

**关键测试点：**
- 用户账号唯一性校验
- 密码强度与重置逻辑
- 数据权限范围控制
- 批量删除与导入校验

### 002-部门管理 (35 条)

**覆盖范围：**
- 部门树展示、展开/折叠
- 部门新增、修改、删除
- 部门状态切换
- 部门树选择器交互

**关键测试点：**
- 同级部门名称唯一性
- 树形结构 ancestors 字段维护
- 停用/删除顺序约束（先子后父）
- 上级部门选择排除逻辑

### 003-岗位管理 (40 条)

**覆盖范围：**
- 岗位列表查询、新增、修改、删除
- 岗位状态切换
- 岗位导出、导入
- 岗位选择器

**关键测试点：**
- 岗位编码/名称全系统唯一性
- 岗位删除时用户关联校验
- 导入模板下载与数据校验

### 004-菜单管理 (38 条)

**覆盖范围：**
- 菜单树展示与管理
- 目录、菜单、按钮三种类型
- 菜单权限标识配置
- 菜单图标选择

**关键测试点：**
- 菜单层级关系维护
- 权限字符串格式校验
- 路由地址唯一性
- 按钮权限与 v-hasPermi 指令联动

### 005-角色管理 (41 条)

**覆盖范围：**
- 角色 CRUD 操作
- 角色菜单权限分配
- 数据权限范围设置
- 角色状态切换

**关键测试点：**
- 角色名称/权限字符唯一性
- 菜单权限树半选状态处理
- 数据范围与自定义部门权限
- 管理员角色保护（不可删除/停用）

### 006-字典管理 (68 条)

**覆盖范围：**
- 字典类型列表查询、新增、修改、删除
- 字典数据列表查询、新增、修改、删除
- 字典缓存刷新
- 字典选择器

**关键测试点：**
- 字典类型名称/键值唯一性
- 字典数据样式标签El-Tag 配置
- 字典缓存同步
- 引用中的字典类型删除保护

### 007-参数设置 (34 条)

**覆盖范围：**
- 参数列表查询、新增、修改、删除

- 系统内置参数保护

**关键测试点：**
- 参数名称/键名唯一性
- 系统内置参数不可删除
- 参数值类型校验（数字、文本、Y/N）
- 参数缓存刷新

### 008-通知公告 (45 条)
