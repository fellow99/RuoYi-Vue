# 016-pool - 前端页面

## 页面概述

**页面名称**: Druid 连接池监控  
**路由路径**: `/monitor/druid`  
**文件路径**: `ruoyi-ui/src/views/monitor/druid/index.vue`  
**权限要求**: 无（使用 Druid 独立认证）

## 页面设计

### 实现方式

使用 iFrame 内嵌 Druid 原生监控页面。

**代码结构：**
```vue
<template>
  <i-frame :src="url" />
</template>

<script>
import iFrame from "@/components/iFrame/index"

export default {
  name: "Druid",
  components: { iFrame },
  data() {
    return {
      url: process.env.VUE_APP_BASE_API + "/druid/login.html"
    }
  }
}
</script>
```

## iFrame 组件

### 组件文件

**路径**: `ruoyi-ui/src/components/iFrame/index.vue`

**功能**: 封装 iFrame，提供统一的嵌入页面体验

### 组件属性

```javascript
props: {
  src: {
    type: String,
    required: true,
    default: ''
  }
}
```

### 组件样式

```css
iframe {
  width: 100%;
  height: calc(100vh - 120px);  // 减去头部和侧边栏高度
  border: none;
  overflow: hidden;
}
```

## 交互功能

### 1. 页面加载
- 自动加载 Druid 登录页面
- 记住登录状态（会话）
- 加载失败时显示错误

### 2. 导航
- Druid 内部导航在 iFrame 内完成
- 不影响 RuoYi 主系统导航
- 支持浏览器前进/后退

### 3. 刷新
- 支持手动刷新 iFrame
- 支持自动刷新（可配置）
- 刷新保持登录状态

## 性能优化

### 1. 懒加载
- iFrame 仅在访问时加载
- 避免预加载占用资源

### 2. 缓存策略
- Druid 页面由服务端缓存
- 静态资源浏览器缓存
- 统计数据内存缓存

### 3. 资源优化
- 压缩 Druid 静态资源
- 启用 Gzip 压缩
- 使用 CDN（可选）

## 安全考虑

### 1. 访问控制
- Druid 独立认证
- 可配置 IP 白名单
- 会话超时自动登出

### 2. 数据脱敏
- URL 脱敏显示
- 用户名脱敏显示
- 密码不显示

### 3. 操作限制
- 生产环境禁止重置统计
- 限制导出功能
- 记录操作日志

## 浏览器兼容性

- Chrome ≥ 60 ✓
- Firefox ≥ 55 ✓
- Safari ≥ 11 ✓
- Edge ≥ 79 ✓
- IE 11（部分功能受限）

## 常见问题

### 1. iFrame 跨域问题
**现象**: iFrame 无法加载  
**解决**: 配置正确的 API 代理

### 2. 登录状态丢失
**现象**: 需要频繁登录  
**解决**: 检查会话配置和超时时间

### 3. 样式错乱
**现象**: Druid 页面样式异常  
**解决**: 检查 CSS 路径和资源加载

### 4. 性能问题
**现象**: 监控页面加载慢  
**解决**: 优化统计配置，限制数据量
