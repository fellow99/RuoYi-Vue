# 016-连接池监视 - 测试用例

**模块编号：** 016
**模块名称：** 连接池监视（Druid 数据源监控）
**版本：** 3.9.1
**最后更新：** 2026-05-04

---

## 一、测试概述

### 1.1 测试范围

本测试覆盖连接池监视（Druid 数据源监控）模块的全链路功能，包括：

- **iFrame 嵌入集成**：通过内嵌 iFrame 组件加载 Druid 原生监控页面，验证 iFrame 与 RuoYi 主系统的兼容性
- **Druid 独立认证**：Druid Monitor 的独立登录验证、会话管理、IP 白名单/黑名单控制
- **数据源监控**：连接池状态查看、活跃/空闲连接数、数据源配置参数
- **SQL 监控**：SQL 执行统计、多字段排序、慢查询检测与阈值配置
- **安全监控**：Wall 防火墙违规拦截统计、白名单管理
- **连接管理**：连接池重置、统计数据清除（生产环境禁用控制）
- **应用监控**：Spring Bean 调用统计、URI 请求统计

### 1.2 测试类型

| 测试类型 | 占比 | 说明 |
|---------|------|------|
| 功能测试 | 45% | Druid 登录、数据源监控、SQL 监控、连接池操作、各监控子页面 |
| 界面测试 | 19% | iFrame 嵌入显示、响应式适配、Druid 页面布局 |
| 权限测试 | 13% | Druid 独立认证、会话管理、IP 白名单 |
| 异常测试 | 23% | iFrame 加载失败、认证失败、连接池异常、内存限制 |
