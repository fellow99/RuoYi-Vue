# 登录日志功能规格 (011-login-log)

**模块编号：** 011  
**模块名称：** 登录日志 (LoginLog)  
**最后更新：** 2026-03-12

---

## 一、功能概述

### 1.1 功能描述

登录日志模块用于记录和追踪系统所有用户的登录行为，包括登录成功和失败的记录。该模块帮助管理员监控用户登录情况，识别异常登录行为，保障系统安全。

### 1.2 核心价值

- **安全审计：** 记录所有登录尝试，满足安全合规要求
- **异常监控：** 发现暴力破解、异常 IP 登录等安全风险
- **问题排查：** 用户反馈登录问题时，可查询登录记录
- **账户保护：** 支持账户解锁功能，处理误锁定情况

### 1.3 用户角色

| 角色 | 权限说明 |
|------|----------|
| 系统管理员 | 查看、删除、导出、清空登录日志，解锁用户 |
| 普通用户 | 无权限访问 |

## 二、功能需求

### 2.1 日志记录

#### FR-011-001 自动记录
系统应自动记录所有登录尝试：
- 用户登录成功记录
- 用户登录失败记录
- 验证码错误记录
- 账户锁定记录
- 账户解锁记录

#### FR-011-002 记录内容
每条登录日志应包含：
- 用户账号
- 登录状态（成功/失败）
- 登录 IP 地址
- 登录地点
- 浏览器类型
- 操作系统
- 提示消息
- 登录时间

#### FR-011-003 记录方式
- 登录成功后异步记录
- 登录失败时同步记录
- 支持密码错误次数统计

### 2.2 日志查询

#### FR-011-004 列表查询
系统应提供登录日志列表查询功能：
- 支持分页显示（默认 10 条/页）
- 支持按登录地址模糊搜索
- 支持按用户名称模糊搜索
- 支持按登录状态筛选
- 支持按登录时间范围筛选
- 默认按登录时间倒序排列

#### FR-011-005 排序功能
- 支持按用户名称排序
- 支持按登录日期排序
- 支持升序/降序切换

### 2.3 日志管理

#### FR-011-006 批量删除
- 支持单选删除
- 支持多选批量删除
- 删除前需二次确认
- 删除后刷新列表

#### FR-011-007 清空日志
- 支持一键清空所有登录日志
- 清空前需二次确认（警示）
- 清空操作使用 TRUNCATE 方式

#### FR-011-008 导出功能
- 支持将查询结果导出为 Excel 文件
- 导出文件名包含时间戳
- 导出内容包含所有字段

### 2.4 账户管理

#### FR-011-009 账户解锁
- 支持解锁被锁定的用户账户
- 解锁前需二次确认
- 解锁后清除登录错误记录
- 支持单选解锁

## 三、权限要求

### 3.1 权限标识

| 功能 | 权限标识 | 说明 |
|------|----------|------|
| 查看列表 | `monitor:logininfor:list` | 查看登录日志列表 |
| 删除日志 | `monitor:logininfor:remove` | 删除登录日志 |
| 导出日志 | `monitor:logininfor:export` | 导出登录日志 |
| 解锁用户 | `monitor:logininfor:unlock` | 解锁用户账户 |

### 3.2 权限控制
- 所有接口均需通过 `@PreAuthorize` 注解进行权限校验
- 前端按钮根据权限动态显示/隐藏
- 无权限访问返回 403 错误

---

## 四、业务规则

### 4.1 登录状态

| 值 | 状态 | 说明 |
|----|------|------|
| 0 | SUCCESS | 登录成功 |
| 1 | ERROR | 登录失败 |

### 4.2 失败处理

- 密码错误 5 次后锁定账户 10 分钟
- 锁定期间禁止登录
- 管理员可手动解锁账户
- 解锁后错误计数清零

### 4.3 IP 记录

- 记录登录时的 IP 地址
- 通过 IP 解析服务获取地理位置
- 支持 IPv4 和 IPv6

---

## 五、数据约束

### 5.1 数据量管理
- 建议定期清理历史日志（如保留 3 个月）
- 大数据量时建议按时间分表或归档
- 清空操作使用 TRUNCATE，谨慎使用

### 5.2 性能要求
- 日志记录应采用异步方式（成功时）
- 列表查询响应时间 < 2 秒（10 万条数据内）
- 支持按时间范围索引优化查询

---

## 六、异常处理

### 6.1 记录异常
- 登录失败时记录详细错误信息
- 错误消息包含失败原因
- 不影响登录流程正常返回

### 6.2 查询异常
- 查询条件为空时，返回全部数据（分页）
- 查询超时返回友好提示
- 数据库异常记录系统日志

---

## 七、安全策略

### 7.1 密码错误处理
- 连续密码错误 5 次锁定账户
- 锁定时间 10 分钟
- 锁定期间提示"账户已锁定，请稍后再试"

### 7.2 异常登录监控
- 同一 IP 频繁登录失败，记录告警
- 异地登录记录详细位置信息
- 支持黑名单 IP 禁止登录

## 九、验收标准

### 9.1 功能验收
- [ ] 所有登录尝试能自动记录日志
- [ ] 日志内容完整准确
- [ ] 查询功能正常，支持所有筛选条件
- [ ] 删除功能正常，支持批量删除
- [ ] 导出功能正常，Excel 格式正确
- [ ] 清空功能正常，有二次确认
- [ ] 账户解锁功能正常

### 9.2 性能验收
- [ ] 日志记录不影响登录性能
- [ ] 列表查询响应时间 < 2 秒
- [ ] 支持 10 万 + 数据量正常查询

### 9.3 安全验收
- [ ] 权限控制有效，无权限无法访问
- [ ] 敏感操作有二次确认
- [ ] 密码错误锁定机制有效
- [ ] 日志内容不包含密码明文
