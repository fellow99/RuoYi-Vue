# 011-登录日志 - 测试用例

**模块编号：** 011  
**模块名称：** 登录日志  
**版本：** 3.9.1  
**最后更新：** 2026-05-04

---

## 一、测试概述

### 1.1 测试范围

本次测试覆盖登录日志模块的全部功能，包括登录日志列表查询、多条件筛选、批量删除、清空日志、导出 Excel、解锁用户账户、登录统计与异常登录检测，以及相关的权限控制与异常处理。

### 1.2 测试类型

| 测试类型 | 占比 | 说明 |
|---------|------|------|
| 功能测试 | 50% | 核心CRUD、查询筛选、导出、解锁等业务逻辑 |
| 界面测试 | 18% | 页面布局、组件渲染、交互反馈 |
| 权限测试 | 16% | 按钮权限控制、接口权限校验 |
| 异常测试 | 16% | 边界条件、空数据、网络异常、并发冲突 |

### 1.3 测试环境

- 浏览器：Chrome 90+, Firefox 88+
- 分辨率：1920×1080 / 1366×768
- 用户角色：系统管理员（admin）、普通用户（user）
