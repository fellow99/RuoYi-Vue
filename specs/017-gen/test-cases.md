## 一、测试概述

### 1.1 测试范围

本测试用例覆盖代码生成模块的全部功能，包括：
- 生成表列表查询、搜索与排序
- 数据库表导入、创建表结构
- 业务信息编辑、字段信息编辑
- 代码预览（多语言语法高亮）
- 代码生成（ZIP下载、本地路径、批量）
- 同步数据库表结构
- 删除生成记录

### 1.2 测试类型

| 测试类型 | 占比 | 说明 |
|---------|------|------|
| 功能测试 | 50% | 核心CRUD及业务逻辑 |
| 界面测试 | 20% | 页面布局、交互 |
| 权限测试 | 15% | 按钮权限、数据权限 |
| 异常测试 | 15% | 边界条件、异常处理 |

### 1.3 测试环境

| 项目 | 配置 |
|------|------|
| 操作系统 | Linux / Windows 10+ |
| 浏览器 | Chrome 90+, Firefox 88+, Edge 90+ |
| 后端框架 | Spring Boot 2.x |
| 前端框架 | Vue 2.x + Element UI |
| 数据库 | MySQL 5.7+ |
| 测试用户 | admin（超级管理员） |
| 测试权限 | tool:gen:list, query, import, edit, remove, preview, code |
