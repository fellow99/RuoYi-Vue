## 一、页面概述

### 2.2 搜索区域

**搜索字段：**

| 字段 | 组件类型 | 说明 |

| 表名称 | Input | 模糊匹配 |

**操作按钮：**
- 搜索：执行查询
- 重置：清空搜索条件

### 2.3 工具栏

**按钮列表：**

| 按钮 | 权限 | 说明 |
|------|------|------|
| 生成 | `tool:gen:code` | 批量生成选中表的代码（ZIP 下载） |
| 创建 | admin 角色 | 打开创建表结构对话框 |
| 导入 | `tool:gen:import` | 打开导入表结构对话框 |
| 修改 | `tool:gen:edit` | 修改选中表的配置（单选） |
| 删除 | `tool:gen:remove` | 删除选中表的配置（支持批量） |

| 更新时间 | updateTime | 160 | 支持排序 |

**操作列按钮：**

| 按钮 | 权限 | 说明 |
|------|------|------|

| 编辑 | `tool:gen:edit` | 打开编辑配置对话框 |
| 删除 | `tool:gen:remove` | 删除单条配置 |
| 同步 | `tool:gen:edit` | 同步数据库表结构 |
| 生成代码 | `tool:gen:code` | 下载单表代码 |

## 六、路由配置

**路由路径：** `/tool/gen`

**路由配置：**
```javascript
{
  path: '/tool/gen',
  component: Layout,
  hidden: false,
  children: [{
    path: 'index',
    component: () => import('@/views/tool/gen/index'),
    name: 'Gen',
    meta: { title: '代码生成', icon: 'code', affix: false }
  }]
}
```

**菜单权限：** `tool:gen:list`
