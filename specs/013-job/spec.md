# 定时任务功能规格 (013-job)

**模块编号：** 013  
**模块名称：** 定时任务 (Job)  
**最后更新：** 2026-03-12

---

## 一、功能概述

### 1.1 功能描述

定时任务模块基于 Quartz 调度框架，提供系统定时任务的配置、调度、执行和监控功能。支持 Cron 表达式配置，可实现复杂的定时任务调度需求。

### 1.2 核心价值

- **自动化执行：** 自动执行周期性任务，减少人工干预
- **灵活调度：** 支持 Cron 表达式，满足复杂调度需求
- **任务监控：** 实时查看任务执行状态和日志
- **安全控制：** 任务调用目标白名单，防止恶意调用

### 1.3 用户角色

| 角色 | 权限说明 |
|------|----------|
| 系统管理员 | 查看、新增、修改、删除、执行任务，查看日志 |
| 普通用户 | 无权限访问 |

## 二、功能需求

### 2.1 任务管理

#### FR-013-001 任务配置
系统应支持定时任务配置：
- 任务名称
- 任务组名
- 调用目标字符串（Bean 方法或类方法）
- Cron 执行表达式
- 任务状态（正常/暂停）
- 并发执行策略（允许/禁止）
- 计划策略（立即执行/执行一次/放弃执行）

#### FR-013-002 任务 CRUD
- 支持新增定时任务
- 支持修改定时任务
- 支持删除定时任务
- 支持查看任务详情

#### FR-013-003 任务状态管理
- 支持启动任务（正常状态）
- 支持暂停任务（暂停状态）
- 支持立即执行一次任务
- 任务状态变更同步到 Quartz 调度器

### 2.2 任务执行

#### FR-013-004 调用方式
支持两种调用方式：
- Bean 调用示例：`ryTask.ryParams('ry')`
- 类调用示例：`com.ruoyi.quartz.task.RyTask.ryParams('ry')`

#### FR-013-005 参数支持
支持以下参数类型：
- 字符串
- 布尔类型
- 长整型
- 浮点型
- 整型

#### FR-013-006 安全校验
- Cron 表达式有效性校验
- 调用目标白名单校验
- 禁止 RMI、LDAP、HTTP(S) 调用
- 防止恶意代码执行

### 2.3 任务调度

#### FR-013-007 调度策略
- 基于 Quartz 调度器
- 支持并发控制
- 支持错过执行策略
- 任务变更自动更新调度器

#### FR-013-008 初始化加载
- 系统启动时自动加载数据库任务
- 同步任务到 Quartz 调度器
- 防止手动修改数据库导致不同步

### 2.4 任务日志

#### FR-013-009 日志记录
- 记录每次任务执行情况
- 记录执行开始和停止时间
- 记录执行状态（成功/失败）
- 记录异常信息

#### FR-013-010 日志查询
- 支持按任务查询执行日志
- 支持按状态筛选
- 支持按时间范围筛选

## 三、权限要求

### 3.1 权限标识

| 功能 | 权限标识 | 说明 |
|------|----------|------|
| 查看列表 | `monitor:job:list` | 查看定时任务列表 |
| 查看详情 | `monitor:job:query` | 查看任务详细和日志 |
| 新增任务 | `monitor:job:add` | 新增定时任务 |
| 修改任务 | `monitor:job:edit` | 修改定时任务 |
| 删除任务 | `monitor:job:remove` | 删除定时任务 |
| 状态变更 | `monitor:job:changeStatus` | 启动/暂停/执行任务 |
| 导出任务 | `monitor:job:export` | 导出任务列表 |

### 3.2 权限控制
- 所有接口均需通过 `@PreAuthorize` 注解进行权限校验
- 前端按钮根据权限动态显示/隐藏
- 无权限访问返回 403 错误

## 四、业务规则

### 4.1 任务状态

| 值 | 状态 | 说明 |
|----|------|------|
| 0 | 正常 | 任务正常调度执行 |
| 1 | 暂停 | 任务暂停，不执行 |

### 4.2 任务组名

| 值 | 组名 | 说明 |
|----|------|------|
| DEFAULT | 默认组 | 系统默认任务组 |
| SYSTEM | 系统组 | 系统任务组 |

### 4.3 并发执行策略

| 值 | 策略 | 说明 |
|----|------|------|
| 0 | 允许 | 允许并发执行 |
| 1 | 禁止 | 禁止并发执行（默认） |

### 4.4 错过执行策略

| 值 | 策略 | 说明 |
|----|------|------|
| 1 | 立即执行 | 错过执行后立即执行 |
| 2 | 执行一次 | 错过执行后执行一次 |
| 3 | 放弃执行 | 错过执行后放弃（默认） |

### 4.5 Cron 表达式

- 支持标准 Cron 表达式（5 个字段）
- 支持秒级 Cron 表达式（6 个字段）
- 提供 Cron 表达式生成器

## 五、安全规则

### 5.1 调用目标限制

**禁止的调用：**
- RMI 调用：`rmi://`
- LDAP 调用：`ldap://`、`ldaps://`
- HTTP 调用：`http://`、`https://`

**白名单校验：**
- 只允许调用配置白名单内的类和方法
- 防止任意代码执行

### 5.2 参数校验

- Cron 表达式必须有效
- 调用目标字符串长度限制（500 字符）
- 任务名称长度限制（64 字符）

---

## 六、数据约束

### 6.1 数据量管理
- 建议定期清理历史日志（如保留 1 个月）
- 任务执行日志量大时考虑分表

### 6.2 性能要求
- 任务执行不影响主业务流程
- 任务调度准时性高
- 支持多任务并发执行

---

## 七、异常处理

### 7.1 执行异常
- 任务执行异常记录到日志
- 不影响其他任务执行
- 支持异常告警（可扩展）

### 7.2 调度异常
- Cron 表达式无效时拒绝保存
- 调度器异常记录系统日志
- 系统重启自动恢复任务
