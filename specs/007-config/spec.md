# 007-Config 参数管理模块功能规格

## 1. 模块概述

参数管理模块用于管理系统的配置参数，提供系统运行时的各种配置项的维护功能。
通过参数管理，可以实现系统配置的动态调整，无需修改代码或重启系统。

## 2. 功能范围

### 2.1 参数配置管理
- 参数配置的增删改查
- 参数键名唯一性校验
- 系统内置参数保护
- 参数缓存管理

## 3. 功能特性

| 功能点 | 描述 | 权限标识 |
|--------|------|----------|
| 查询参数列表 | 支持分页查询，可按名称、键名、类型筛选 | system:config:list |
| 查询参数详情 | 根据参数 ID 获取详细信息 | system:config:query |
| 新增参数配置 | 创建新的参数配置，需校验键名唯一性 | system:config:add |
| 修改参数配置 | 更新参数配置信息，需校验键名唯一性 | system:config:edit |
| 删除参数配置 | 批量删除参数配置（内置参数不可删除） | system:config:remove |
| 导出参数数据 | 导出参数配置数据为 Excel | system:config:export |
| 刷新参数缓存 | 清空并重新加载参数缓存 | system:config:remove |
| 根据键名查询参数值 | 根据参数键名获取参数值（用于系统获取配置） | 无限制 |

## 4. 业务规则

### 4.1 参数配置规则
1. 参数名称不能为空，长度不超过 100 字符
2. 参数键名不能为空，长度不超过 100 字符
3. 参数键值不能为空，长度不超过 500 字符
4. 参数键名在系统内必须唯一
5. 系统内置参数（configType='Y'）不能删除
6. 系统内置参数可以修改
7. 参数状态：Y-是（系统内置），N-否（用户自定义）

### 4.2 缓存规则
1. 参数配置在系统启动时自动加载到缓存
2. 新增、修改、删除参数后自动更新缓存
3. 提供手动刷新缓存功能
4. 缓存键格式：`sys_config:{configKey}`
5. 查询参数值时优先从缓存读取

### 4.3 内置参数示例
| 参数键名 | 参数值 | 说明 |
|----------|--------|------|
| sys.index.skinName | skin-blue | 主框架页默认皮肤样式 |
| sys.index.sideTheme | theme-dark | 主框架页侧边栏主题 |
| sys.account.captchaEnabled | true | 账号自助 - 验证码开关 |
| sys.account.registerUser | false | 账号自助 - 是否开启用户注册 |
| sys.user.initPassword | 123456 | 用户管理 - 账号初始密码 |
| sys.login.blackIPList | - | 用户登录 - 黑名单列表 |
| sys.account.initPasswordModify | 1 | 用户管理 - 初始密码修改策略 |
| sys.account.passwordValidateDays | 0 | 用户管理 - 账号密码更新周期 |

## 5. 用户界面

### 5.1 参数配置管理页面
- 位置：系统管理 > 参数管理
- 功能：参数列表展示、搜索、新增、修改、删除、导出、刷新缓存

### 5.2 页面特性
- 支持按参数名称、参数键名、系统内置类型筛选
- 支持按创建时间范围筛选
- 内置参数有特殊标识
- 支持批量删除（内置参数会提示错误）

## 6. 依赖关系

### 6.1 内部依赖
- 依赖缓存模块（Redis）进行参数缓存
- 依赖权限模块进行接口访问控制

### 6.2 外部依赖
- 无外部依赖

## 7. 性能要求

1. 参数查询响应时间 < 100ms（缓存命中）
2. 参数查询响应时间 < 500ms（数据库查询）
3. 支持至少 100 个参数配置
4. 缓存更新延迟 < 1 秒

## 8. 安全要求

1. 所有写操作需要相应权限
2. 输入数据需要进行长度和格式校验
3. 删除操作需要二次确认
4. 内置参数删除需要友好提示

## 9. 典型使用场景

1. 系统皮肤配置：动态切换系统主题
2. 验证码开关：控制登录是否需要验证码
3. 用户注册开关：控制是否允许用户自主注册
4. 初始密码配置：设置新用户默认密码
5. 密码策略：配置密码修改提醒周期
6. IP 黑名单：配置登录 IP 黑名单
