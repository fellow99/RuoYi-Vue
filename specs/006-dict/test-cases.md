# 006-字典管理 - 测试用例

**模块编号：** 006
**模块名称：** 字典管理
**版本：** 3.9.1
**最后更新：** 2026-05-04

---

## 一、测试概述

### 1.1 测试范围

本模块测试覆盖字典类型的增删改查、导出、缓存刷新、抽屉详情查看，以及字典数据的增删改查、导出、排序、回显样式、状态管理等功能。同时覆盖字典管理的权限控制、表单校验、边界条件、XSS防护、异常处理等场景。

### 1.2 测试类型

| 测试类型 | 占比 | 说明 |
|---------|------|------|
| 功能测试 | 55% | 核心CRUD及业务逻辑 |
| 界面测试 | 15% | 页面布局、交互 |
| 权限测试 | 15% | 按钮权限、数据权限 |
| 异常测试 | 15% | 边界条件、异常处理 |

### 1.3 测试环境

- 浏览器：Chrome 90+, Firefox 88+
- 分辨率：1920×1080 / 1366×768
- 用户角色：管理员、普通用户
