# 006-Dict 字典管理模块功能规格

## 1. 模块概述

字典管理模块用于管理系统中的各类字典数据，提供字典类型和字典数据的维护功能。
通过字典管理，可以实现系统中下拉选项、状态标识等数据的统一管理和动态配置。

## 2. 功能范围

### 2.1 字典类型管理
- 字典类型的增删改查
- 字典类型唯一性校验
- 字典类型状态管理（正常/停用）
- 字典缓存刷新

### 2.2 字典数据管理
- 字典数据的增删改查
- 字典数据排序管理
- 字典数据默认值设置
- 字典数据状态管理（正常/停用）
- 按字典类型查询字典数据

## 3. 功能特性

### 3.1 字典类型功能
| 功能点 | 描述 | 权限标识 |
|--------|------|----------|
| 查询字典类型列表 | 支持分页查询，可按名称、类型、状态筛选 | system:dict:list |
| 查询字典类型详情 | 根据字典 ID 获取详细信息 | system:dict:query |
| 新增字典类型 | 创建新的字典类型，需校验类型唯一性 | system:dict:add |
| 修改字典类型 | 更新字典类型信息，需校验类型唯一性 | system:dict:edit |
| 删除字典类型 | 批量删除字典类型 | system:dict:remove |
| 导出字典类型 | 导出字典类型数据为 Excel | system:dict:export |
| 刷新字典缓存 | 清空并重新加载字典缓存 | system:dict:remove |
| 获取字典选择框列表 | 获取所有正常状态的字典类型（用于前端下拉框） | 无限制 |

### 3.2 字典数据功能
| 功能点 | 描述 | 权限标识 |
|--------|------|----------|
| 查询字典数据列表 | 支持分页查询，可按字典类型、标签、键值筛选 | system:dict:list |
| 查询字典数据详情 | 根据字典编码获取详细信息 | system:dict:query |
| 新增字典数据 | 创建新的字典数据 | system:dict:add |
| 修改字典数据 | 更新字典数据信息 | system:dict:edit |
| 删除字典数据 | 批量删除字典数据 | system:dict:remove |
| 导出字典数据 | 导出字典数据为 Excel | system:dict:export |
| 根据类型查询字典数据 | 根据字典类型获取所有字典数据（用于前端下拉框） | 无限制 |

## 4. 业务规则

### 4.1 字典类型规则
1. 字典类型名称不能为空，长度不超过 100 字符
2. 字典类型标识不能为空，长度不超过 100 字符
3. 字典类型标识必须以字母开头，且只能包含小写字母、数字、下划线
4. 字典类型标识在系统内必须唯一
5. 字典类型状态：0-正常，1-停用

### 4.2 字典数据规则
1. 字典标签不能为空，长度不超过 100 字符
2. 字典键值不能为空，长度不超过 100 字符
3. 字典类型不能为空，必须关联已存在的字典类型
4. 字典排序用于控制字典数据的显示顺序
5. 是否默认：Y-是，N-否
6. 字典数据状态：0-正常，1-停用

### 4.3 缓存规则
1. 字典类型和字典数据在系统启动时自动加载到缓存
2. 新增、修改、删除字典数据后自动更新缓存
3. 提供手动刷新缓存功能
4. 缓存键格式：`sys_dict_type:{dictType}`

## 5. 用户界面

### 5.1 字典类型管理页面
- 位置：系统管理 > 字典管理 > 字典类型
- 功能：字典类型列表展示、搜索、新增、修改、删除、导出、刷新缓存

### 5.2 字典数据管理页面
- 位置：系统管理 > 字典管理 > 字典数据
- 功能：字典数据列表展示、搜索、新增、修改、删除、导出
- 特性：支持按字典类型筛选，显示字典标签和键值的映射关系

## 6. 依赖关系

### 6.1 内部依赖
- 依赖缓存模块（Redis）进行字典数据缓存
- 依赖权限模块进行接口访问控制

### 6.2 外部依赖
- 无外部依赖

## 7. 性能要求

1. 字典数据查询响应时间 < 100ms（缓存命中）
2. 字典数据查询响应时间 < 500ms（数据库查询）
3. 支持至少 1000 个字典类型
4. 每个字典类型支持至少 100 个字典数据

## 8. 安全要求

1. 所有写操作需要相应权限
2. 字典类型标识需要 XSS 防护
3. 输入数据需要进行长度和格式校验
4. 删除操作需要二次确认

## 9. 典型使用场景

1. 用户性别选择：sys_user_sex（男、女、未知）
2. 菜单状态：sys_show_hide（显示、隐藏）
3. 系统开关：sys_normal_disable（正常、停用）
4. 任务状态：sys_job_status（正常、暂停）
5. 是否选项：sys_yes_no（是、否）
