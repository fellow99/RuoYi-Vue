# 008-通知公告 - 测试用例

**模块编号：** 008  
**模块名称：** 通知公告  
**版本：** 3.9.1  
**最后更新：** 2026-05-04

---

## 一、测试概述

### 1.1 测试范围

本模块测试覆盖通知公告的增删改查全流程，包括公告列表查询（按标题、类型、创建人筛选）、新增公告（含富文本编辑器内容编辑）、修改公告、删除公告（单个和批量）、公告状态切换，以及首页公告列表展示、公告已读/未读状态标记等功能。同时覆盖权限控制、表单校验、XSS防护、边界条件等。

### 1.2 测试类型

| 测试类型 | 占比 | 说明 |
|---------|------|------|
| 功能测试 | 55% | 核心CRUD及业务逻辑 |
| 界面测试 | 15% | 页面布局、富文本编辑器交互 |
| 权限测试 | 15% | 按钮权限、数据权限 |
| 异常测试 | 15% | 边界条件、异常处理 |

### 1.3 测试环境

- 浏览器：Chrome 90+, Firefox 88+
- 分辨率：1920×1080 / 1366×768
- 用户角色：管理员、普通用户
