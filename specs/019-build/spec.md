# 019-在线构建器 - 功能规格

**模块编号：** 019  
**模块名称：** 在线构建器 (Form Builder / 表单构建器)  
**所属模块：** 系统工具  
**版本：** 3.9.1  
**最后更新：** 2026-03-12

---

## 一、功能概述

在线构建器是一个可视化的表单设计工具，允许用户通过拖拽组件的方式快速设计和生成 Vue 表单代码。该工具基于 Element UI 组件库，提供丰富的表单组件和灵活的配置选项，支持实时预览和代码导出。

### 1.1 核心功能

- **组件拖拽**：从左侧组件库拖拽组件到中间画布
- **属性配置**：在右侧面板配置组件属性
- **实时预览**：实时查看表单设计效果
- **代码生成**：一键生成 Vue 单文件组件代码
- **代码导出**：支持导出 .vue 文件或复制代码
- **组件库**：提供输入型、选择型、布局型三大类组件
- **表单配置**：配置表单整体属性（尺寸、标签位置等）

### 1.2 技术栈

| 组件 | 版本 | 说明 |
|------|------|------|
| Vue | 2.x | 前端框架 |
| Element UI | 2.x | UI 组件库 |
| VueDraggable | 2.x | 拖拽排序库 |
| JS Beautify | - | 代码格式化 |
| ClipboardJS | - | 剪贴板操作 |

### 1.3 业务规则

1. **组件唯一性**：每个拖入的组件有唯一的 formId 和 vModel
2. **栅格布局**：基于 Element UI 的 24 栅格系统
3. **数据绑定**：自动生成 v-model 双向绑定
4. **校验规则**：支持配置正则校验规则
5. **代码规范**：生成的代码符合 Vue 单文件组件规范

### 2.2 画布区域

**功能描述：** 中间区域为表单设计画布，支持拖拽组件、调整顺序、删除组件

**操作功能：**
- **拖入组件**：从左侧组件库拖入组件
- **调整顺序**：拖拽调整组件顺序
- **选中组件**：点击组件选中，右侧显示属性配置
- **复制组件**：点击复制按钮复制组件
- **删除组件**：点击删除按钮删除组件
- **清空画布**：点击清空按钮清空所有组件

**布局方式：**
- 基于 Element UI 的 el-row 和 el-col
- 默认栅格数：24
- 支持自定义每个组件的栅格数（span）

### 2.4 代码生成

**生成类型：**

| 类型 | 说明 | 输出 |
|------|------|------|
| 导出 vue 文件 | 下载 .vue 文件 | 下载文件 |
| 复制代码 | 复制到剪贴板 | 剪贴板内容 |
| 运行预览 | 弹窗预览效果 | 预览窗口 |

**生成内容：**

1. **Template 部分**
   - el-form 表单结构
   - el-row 和 el-col 布局
   - 各表单组件及属性

2. **Script 部分**
   - data 数据定义
   - formModel 表单数据模型
   - rules 校验规则
   - methods 方法定义

3. **Style 部分**
   - 组件样式
   - 布局样式

**代码格式化：**
- 使用 js-beautify 进行代码格式化
- 遵循 Vue 单文件组件规范

## 三、交互流程

### 3.1 表单设计流程

```
1. 打开表单构建器页面
       ↓
2. 从左侧组件库选择组件
       ↓
3. 拖拽组件到中间画布（或点击组件）
       ↓
4. 在右侧面板配置组件属性
       ↓
5. 重复步骤 2-4 添加更多组件
       ↓
6. 调整组件顺序和布局
       ↓
7. 配置表单整体属性
       ↓
8. 预览表单效果
       ↓
9. 导出代码或下载文件
```

### 3.2 组件配置流程

```
1. 点击画布中的组件（选中）
       ↓
2. 右侧面板显示组件属性
       ↓
3. 修改属性值
       ↓
4. 实时预览效果
       ↓
5. 添加正则校验规则（可选）
       ↓
6. 配置完成
```

### 3.3 代码导出流程

```
1. 完成表单设计
       ↓
2. 点击"导出 vue 文件"或"复制代码"按钮
       ↓
3. 选择生成类型（下载/复制/预览）
       ↓
4. 系统生成代码
       ↓
5. 下载文件或复制到剪贴板
```

## 五、数据模型

### 5.1 表单数据结构

```javascript
{
  formRef: 'elForm',           // 表单 ref
  formModel: 'formData',       // 数据模型名
  formRules: 'rules',          // 校验规则名
  size: 'medium',              // 表单尺寸
  labelPosition: 'right',      // 标签位置
  labelWidth: 100,             // 标签宽度
  gutter: 15,                  // 栅格间隔
  disabled: false,             // 是否禁用
  formBtns: true,              // 是否显示按钮
  fields: [                    // 字段列表
    {
      formId: 101,             // 组件唯一 ID
      renderKey: 1234567890,   // 渲染 key（用于强制更新）
      vModel: 'field101',      // 字段绑定变量
      tag: 'el-input',         // 组件标签
      tagIcon: 'input',        // 组件图标
      label: '单行文本',       // 字段标签
      placeholder: '请输入',   // 占位提示
      span: 24,                // 栅格数
      required: true,          // 是否必填
      regList: [],             // 正则校验列表
      // ... 其他组件属性
    }
  ]
}
```

### 5.2 组件 ID 生成规则

- **formId**：自增数字，从 100 开始
- **vModel**：`field` + formId
- **renderKey**：时间戳（用于强制更新组件）

## 七、限制说明

### 7.1 功能限制

1. **不支持复杂布局**：仅支持基础的行列布局
2. **不支持自定义组件**：只能使用内置组件
3. **不支持动态表单**：不支持运行时动态增减字段
4. **不支持表单联动**：不支持字段间的联动逻辑

### 7.2 代码限制

1. **生成代码需手动集成**：生成的代码需要手动集成到项目中
2. **不生成 API 接口**：仅生成前端表单，不生成后端接口
3. **不生成业务逻辑**：仅生成表单结构，不生成业务处理逻辑
