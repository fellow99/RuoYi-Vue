# 019-在线构建器 - 测试用例

**模块编号：** 019
**模块名称：** 在线构建器
**版本：** 3.9.1
**最后更新：** 2026-05-04

---

## 一、测试概述

### 1.1 测试范围

本测试用例覆盖在线构建器（表单构建器 / Form Builder）模块的全部功能，包括：
- 左侧组件库浏览（输入型、选择型、布局型）
- 拖拽组件到中间画布
- 点击组件添加到画布
- 画布中组件选中、复制、删除、排序
- 右侧属性面板（组件属性、表单属性）配置
- 组件类型切换
- 代码生成（导出.vue文件、复制代码、运行预览）
- 清空画布
- 正则校验规则配置

### 1.2 测试类型

| 测试类型 | 占比 | 说明 |
|---------|------|------|
| 功能测试 | 55% | 拖拽交互、属性配置、代码生成 |
| 界面测试 | 20% | 三栏布局、样式、交互反馈 |
| 权限测试 | 10% | 页面访问控制 |
| 异常测试 | 15% | 边界条件、浏览器兼容性 |

### 1.3 测试环境

| 项目 | 配置 |
|------|------|
| 操作系统 | Linux / Windows 10+ |
| 浏览器 | Chrome 90+, Firefox 88+, Edge 90+ |
| 前端框架 | Vue 2.x + Element UI |
| 拖拽库 | vuedraggable 2.x |
| 剪贴板 | ClipboardJS |
| 代码格式化 | js-beautify |
| 测试用户 | 任意已登录用户 |
| 注意 | 纯前端工具、无后端API |
