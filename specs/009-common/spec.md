# 009-Common 公共模块功能规格

## 1. 模块概述

公共模块包含系统的基础支撑功能，主要包括操作日志、登录日志、在线用户等监控和管理功能。
这些功能为系统的安全运行、行为审计、状态监控提供基础支持。

## 2. 功能范围

### 2.1 操作日志管理
- 操作日志查询
- 操作日志导出
- 操作日志删除
- 操作日志清空

### 2.2 登录日志管理
- 登录日志查询
- 登录日志导出
- 登录日志删除
- 登录日志清空
- 账户解锁

### 2.3 在线用户管理
- 在线用户查询
- 用户强退

## 3. 功能特性

### 3.1 操作日志功能
| 功能点 | 描述 | 权限标识 |
|--------|------|----------|
| 查询操作日志列表 | 支持分页查询，可按模块、操作类型、状态等筛选 | monitor:operlog:list |
| 导出操作日志 | 导出操作日志数据为 Excel | monitor:operlog:export |
| 删除操作日志 | 批量删除操作日志 | monitor:operlog:remove |
| 清空操作日志 | 清空所有操作日志 | monitor:operlog:remove |

### 3.2 登录日志功能
| 功能点 | 描述 | 权限标识 |
|--------|------|----------|
| 查询登录日志列表 | 支持分页查询，可按用户名、IP 地址、状态等筛选 | monitor:logininfor:list |
| 导出登录日志 | 导出登录日志数据为 Excel | monitor:logininfor:export |
| 删除登录日志 | 批量删除登录日志 | monitor:logininfor:remove |
| 清空登录日志 | 清空所有登录日志 | monitor:logininfor:remove |
| 账户解锁 | 解锁因密码错误次数过多被锁定的账户 | monitor:logininfor:unlock |

### 3.3 在线用户功能
| 功能点 | 描述 | 权限标识 |
|--------|------|----------|
| 查询在线用户列表 | 查询当前在线用户列表 | monitor:online:list |
| 用户强退 | 强制退出指定用户 | monitor:online:force |

## 4. 业务规则

### 4.1 操作日志规则
1. 操作日志自动记录，无需手动创建
2. 操作日志记录所有带有@Log 注解的接口调用
3. 记录内容包括：操作模块、业务类型、请求方法、操作人员、请求 URL、IP 地址、请求参数、返回结果、操作状态、错误消息、消耗时间
4. 操作日志不支持修改
5. 业务类型：0-其它，1-新增，2-修改，3-删除，4-授权，5-导出，6-导入，7-强退，8-生成代码，9-清空数据

### 4.2 登录日志规则
1. 登录日志自动记录，无需手动创建
2. 记录内容包括：用户账号、IP 地址、登录地点、浏览器类型、操作系统、登录状态、提示消息、访问时间
3. 登录状态：0-成功，1-失败
4. 登录日志不支持修改
5. 连续登录失败多次后账户会被锁定

### 4.3 在线用户规则
1. 在线用户信息存储在 Redis 中
2. 用户登录后自动创建在线用户记录
3. 用户退出后自动删除在线用户记录
4. 支持手动强退在线用户
5. 强退后用户需要重新登录

## 5. 用户界面

### 5.1 操作日志管理页面
- 位置：系统监控 > 操作日志
- 功能：操作日志列表展示、搜索、导出、删除、清空

### 5.2 登录日志管理页面
- 位置：系统监控 > 登录日志
- 功能：登录日志列表展示、搜索、导出、删除、清空、账户解锁

### 5.3 在线用户管理页面
- 位置：系统监控 > 在线用户
- 功能：在线用户列表展示、搜索、强退

## 6. 依赖关系

### 6.1 内部依赖
- 依赖 Redis 存储在线用户信息
- 依赖权限模块进行接口访问控制
- 依赖 AOP 切面自动记录操作日志

### 6.2 外部依赖
- IP 地址库（用于解析 IP 地理位置）

## 7. 性能要求

1. 操作日志记录不影响业务接口性能（异步记录）
2. 日志查询响应时间 < 1 秒
3. 支持至少 100 万条日志记录
4. 在线用户信息实时更新

## 8. 安全要求

1. 所有管理操作需要相应权限
2. 日志数据不支持修改，保证数据真实性
3. 敏感信息（如密码）需要脱敏处理
4. 删除和清空操作需要二次确认

## 9. 典型使用场景

1. **操作审计：** 查看特定用户的操作记录
2. **安全分析：** 分析登录失败记录，发现异常登录
3. **问题排查：** 通过操作日志排查系统问题
4. **用户管理：** 查看在线用户，强退异常用户
5. **账户解锁：** 为忘记密码的用户解锁账户

## 10. 日志记录策略

### 10.1 自动记录
- 使用 AOP 切面自动记录带有@Log 注解的接口
- 记录时机：接口执行完成后
- 记录方式：异步记录，不影响业务性能

### 10.2 记录内容
- 操作模块（title）
- 业务类型（businessType）
- 请求方法（method）
- 请求方式（GET/POST/PUT/DELETE）
- 操作人员（operName）
- 部门名称（deptName）
- 请求 URL（operUrl）
- 操作 IP（operIp）
- 操作地点（operLocation）
- 请求参数（operParam）
- 返回结果（jsonResult）
- 操作状态（status）
- 错误消息（errorMsg）
- 操作时间（operTime）
- 消耗时间（costTime）

## 11. 数据保留策略

1. 操作日志和登录日志建议定期清理
2. 可根据时间范围清理历史日志
3. 重要日志建议导出备份后再删除
4. 在线用户数据实时同步，无需手动管理
