# 012-在线用户 - 测试用例

**模块编号：** 012  
**模块名称：** 在线用户  
**版本：** 3.9.1  
**最后更新：** 2026-05-04

---

## 一、测试概述

### 1.1 测试范围

本次测试覆盖在线用户模块的全部功能，包括在线用户实时列表查询、按 IP 地址和用户名称筛选、前端分页展示、强制退出用户、会话超时管理以及相关的权限控制与异常处理。由于在线用户数据来源于 Redis 缓存，测试需注意数据实时性和前端分页特性。

### 1.2 测试类型

| 测试类型 | 占比 | 说明 |
|---------|------|------|
| 功能测试 | 52% | 在线列表查询、条件筛选、强制退出、会话超时等核心业务 |
| 界面测试 | 17% | 页面布局、组件渲染、前端分页交互 |
| 权限测试 | 14% | 按钮权限控制、接口权限校验 |
| 异常测试 | 17% | 边界条件、Redis 异常、网络异常、空数据 |

### 1.3 测试环境

- 浏览器：Chrome 90+, Firefox 88+
- 分辨率：1920×1080 / 1366×768
- 用户角色：系统管理员（admin）、普通用户（user）
- 后端存储：Redis 缓存（登录 Token 数据）
