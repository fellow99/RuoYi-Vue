## 1. 部门管理功能

### US-002-001 查看部门树

**作为** 系统用户  
**我想要** 查看组织部门树形结构  
**以便于** 了解公司的组织架构

**验收标准**：
- [ ] 以树形结构展示所有部门
- [ ] 可以展开/折叠子部门
- [ ] 显示部门名称、状态等信息

**优先级**：高  
**故事点**：1

---

### US-002-002 新增部门

**作为** 系统管理员  
**我想要** 新增部门  
**以便于** 扩展公司的组织架构

**验收标准**：
- [ ] 可以选择上级部门（顶级部门无需选择）
- [ ] 必须填写部门名称（同级唯一）
- [ ] 必须填写显示顺序
- [ ] 可以填写负责人、联系电话、邮箱
- [ ] 部门名称同级不能重复

**优先级**：高  
**故事点**：3

---

### US-002-003 修改部门

**作为** 系统管理员  
**我想要** 修改部门信息  
**以便于** 更新部门的基本信息

**验收标准**：
- [ ] 可以修改部门名称
- [ ] 可以修改上级部门
- [ ] 可以修改显示顺序
- [ ] 可以修改负责人、联系电话、邮箱
- [ ] 同级部门名称不能重复
- [ ] 不能修改顶级部门的父部门

**优先级**：高  
**故事点**：3

---

### US-002-004 删除部门

**作为** 系统管理员  
**我想要** 删除部门  
**以便于** 移除不存在的部门

**验收标准**：
- [ ] 部门下存在子部门时不允许删除
- [ ] 部门下存在用户时不允许删除
- [ ] 删除成功后自动更新子部门的祖先字段

**优先级**：中  
**故事点**：2

---

### US-002-005 修改部门状态

**作为** 系统管理员  
**我想要** 启用或停用部门  
**以便于** 控制部门及下属员工的系统访问

**验收标准**：
- [ ] 可以快速切换部门状态（启用/停用）
- [ ] 停用部门时，该部门下的用户也会被停用
- [ ] 停用部门前需先停用所有子部门

**优先级**：中  
**故事点**：2

---

### US-002-006 查询部门下用户

**作为** 系统管理员  
**我想要** 查看部门下的用户列表  
**以便于** 了解某个部门的人员构成

**验收标准**：
- [ ] 可以查看部门下的所有用户
- [ ] 包括子部门的用户（可选）
- [ ] 显示用户账号、昵称、状态等信息

**优先级**：中  
**故事点**：2

---

## 2. 部门选择功能

### US-002-007 部门树选择

**作为** 系统用户  
**我想要** 在用户管理等部门中选择部门  
**以便于** 为用户分配所属部门

**验收标准**：
- [ ] 显示部门树供选择
- [ ] 可以搜索部门名称
- [ ] 支持多选或单选模式
- [ ] 禁用的部门不可选择

**优先级**：高  
**故事点**：2
