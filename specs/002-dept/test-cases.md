# 002-部门管理 - 测试用例

**模块编号：** 002  
**模块名称：** 部门管理  
**版本：** 3.9.1  
**最后更新：** 2026-05-04

---

## 一、测试概述

### 1.1 测试范围

本测试用例覆盖部门管理模块的全部功能，包括部门树形列表查询、新增部门、修改部门、删除部门、修改部门状态、查看部门下用户以及部门树选择。测试范围涵盖树形结构的增删改查、状态切换、排序管理以及数据权限控制。

### 1.2 测试类型

| 测试类型 | 占比 | 说明 |
|---------|------|------|
| 功能测试 | 60% | 树形CRUD及业务逻辑 |
| 界面测试 | 15% | 树形表格、对话框布局 |
| 权限测试 | 10% | 按钮权限 |
| 异常测试 | 15% | 边界条件、删除/停用约束 |

### 1.3 测试环境

- 浏览器：Chrome 90+, Firefox 88+
- 分辨率：1920×1080 / 1366×768
- 用户角色：管理员、普通用户
