## 1. 菜单管理功能

### US-004-001 查看菜单树

**作为** 系统管理员  
**我想要** 查看菜单树形结构  
**以便于** 了解系统的功能模块组织

**验收标准**：
- [ ] 以树形结构展示所有菜单
- [ ] 可以展开/折叠目录
- [ ] 显示菜单名称、图标、状态等信息

**优先级**：高  
**故事点**：1

---

### US-004-002 新增菜单

**作为** 系统管理员  
**我想要** 新增菜单  
**以便于** 为系统添加新的功能模块

**验收标准**：
- [ ] 可以选择父级菜单（顶级菜单无需选择）
- [ ] 必须填写菜单名称
- [ ] 必须选择菜单类型（目录/菜单/按钮）
- [ ] 目录类型可无组件路径，菜单类型必须有
- [ ] 按钮类型必须有父菜单
- [ ] 同级菜单名称不能重复

**优先级**：高  
**故事点**：5

---

### US-004-003 修改菜单

**作为** 系统管理员  
**我想要** 修改菜单信息  
**以便于** 更新菜单的配置

**验收标准**：
- [ ] 可以修改菜单名称、图标
- [ ] 可以修改路由地址、组件路径
- [ ] 可以修改权限标识
- [ ] 可以修改显示顺序
- [ ] 可以修改菜单类型
- [ ] 外链类型地址必须以http(s)://开头

**优先级**：高  
**故事点**：3

---

### US-004-004 删除菜单

**作为** 系统管理员  
**我想要** 删除菜单  
**以便于** 移除不需要的功能模块

**验收标准**：
- [ ] 菜单存在子菜单时不允许删除
- [ ] 菜单已分配给角色时不允许删除
- [ ] 删除后自动更新角色的菜单权限

**优先级**：中  
**故事点**：2

---

### US-004-005 修改菜单状态

**作为** 系统管理员  
**我想要** 显示或隐藏菜单  
**以便于** 控制菜单的可见性

**验收标准**：
- [ ] 可以设置是否显示（显示/隐藏）
- [ ] 可以设置是否启用（启用/停用）
- [ ] 隐藏的菜单用户看不到

**优先级**：中  
**故事点**：2

---

## 2. 菜单权限配置

### US-004-006 菜单排序

**作为** 系统管理员  
**我想要** 调整菜单的显示顺序  
**以便于** 按照业务需要排列菜单

**验收标准**：
- [ ] 可以拖拽调整菜单顺序
- [ ] 也可以通过输入数字调整

**优先级**：低  
**故事点**：2

---

### US-004-007 按钮权限配置

**作为** 系统管理员  
**我想要** 配置按钮级别权限  
**以便于** 控制用户的操作权限

**验收标准**：
- [ ] 可以在菜单下添加按钮
- [ ] 按钮可以配置权限标识
- [ ] 按钮可以设置是否显示

**优先级**：高  
**故事点**：3
