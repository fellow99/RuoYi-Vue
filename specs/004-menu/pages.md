## 三、功能区域

### 3.1 搜索区域

| 字段 | 组件类型 | 说明 |
|------|---------|------|
| 菜单名称 | Input | 模糊匹配 |

| 按钮 | 权限 | 说明 |
|------|------|------|

### 3.3 树形表格

| 列名 | 字段 | 宽度 | 说明 |

## 四、新增/编辑对话框

**表单字段：**

| 字段 | 组件类型 | 必填 | 说明 |
|------|---------|------|------|
| 上级菜单 | Treeselect | 是 | 树形选择 |
| 菜单类型 | Radio | 是 | M 目录/C 菜单/F 按钮 |
| 菜单名称 | Input | 是 | 50 字符内 |
| 图标 | Input | 否 | 菜单图标 |
| 显示顺序 | InputNumber | 是 | - |
| 路由地址 | Input | C/M 必填 | 200 字符内 |
| 组件路径 | Input | C 必填 | 255 字符内 |
| 路由名称 | Input | 否 | 默认自动生成 |
| 是否外链 | Radio | 否 | 0 是/1 否 |
| 是否缓存 | Radio | 否 | 0 缓存/1 不缓存 |
| 显示状态 | Radio | 否 | 0 显示/1 隐藏 |
| 菜单状态 | Radio | 否 | 0 正常/1 停用 |
| 权限标识 | Input | F 必填 | 100 字符内 |
| 备注 | Input | 否 | 500 字符 |

**表单联动：**
- 选择目录（M）：隐藏组件路径、权限标识
- 选择菜单（C）：显示路由地址、组件路径
- 选择按钮（F）：显示权限标识，隐藏路由相关

## 八、交互细节

## 九、注意事项

1. **菜单类型选择**：不同类型显示不同字段
2. **上级菜单选择**：排除当前部门及子部门
3. **权限标识格式**：遵循 `模块：功能：操作` 规范
4. **组件路径**：必须与前端实际路径一致
