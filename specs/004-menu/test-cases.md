# 004-菜单管理 - 测试用例

**模块编号：** 004  
**模块名称：** 菜单管理  
**版本：** 3.9.1  
**最后更新：** 2026-05-04

---

## 一、测试概述

### 1.1 测试范围

本模块测试覆盖菜单管理的全部功能：菜单树形结构展示与查询、三种菜单类型（目录M/菜单C/按钮F）的增删改操作、菜单状态管理（显示/隐藏、启用/停用）、菜单排序功能、按钮权限标识配置、以及菜单删除约束校验。同时覆盖前端页面的界面交互、权限控制（按钮可见性）、异常场景（边界值、并发操作、网络异常）。

### 1.2 测试类型

| 测试类型 | 占比 | 说明 |
|---------|------|------|
| 功能测试 | 55% | 核心CRUD及业务逻辑（菜单的增删改查、排序、状态管理） |
| 界面测试 | 20% | 页面布局、树形表格渲染、表单联动、图标选择器 |
| 权限测试 | 10% | 按钮权限控制（v-hasPermi）、数据访问权限 |
| 异常测试 | 15% | 边界条件、字段校验、重复性校验、删除约束、并发操作 |

### 1.3 测试环境

- 浏览器：Chrome 90+, Firefox 88+
- 分辨率：1920×1080 / 1366×768
- 用户角色：管理员（admin）、普通用户（无菜单权限）
