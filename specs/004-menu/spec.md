# 004-菜单管理 - 功能规格

**模块编号：** 004  
**模块名称：** 菜单管理 (Menu Management)  
**所属模块：** 系统管理  
**版本：** 3.9.1  
**最后更新：** 2026-03-12

---

## 一、功能概述

菜单管理用于配置系统菜单、操作权限、按钮权限标识等。菜单是系统权限控制的基础，通过角色 - 菜单关联实现用户权限控制。

### 1.1 核心功能

- **菜单 CRUD**：新增、查询、修改、删除菜单
- **菜单类型**：支持目录（M）、菜单（C）、按钮（F）三种类型
- **树形结构**：支持多层级菜单树形展示
- **权限标识**：配置菜单/按钮的权限字符串
- **路由配置**：配置前端路由地址、组件路径
- **状态管理**：显示/隐藏、启用/停用菜单

### 1.2 业务规则

1. **菜单名称唯一性**：同级菜单名称不能重复
2. **路由地址唯一性**：路由地址（path）在全系统建议唯一
3. **路由名称唯一性**：路由名称（routeName）在全系统建议唯一
4. **类型约束**：
   - 目录（M）：可包含子菜单，无组件路径
   - 菜单（C）：必须有组件路径，可包含按钮
   - 按钮（F）：必须有父菜单，配置权限标识
5. **外链校验**：类型为外链时，地址必须以 http(s)://开头
6. **删除约束**：菜单已分配给角色时不允许删除

## 二、功能详细设计

### 2.1 菜单列表查询

**功能描述：** 以树形结构展示所有菜单

**查询条件：**
- 菜单名称（模糊匹配）
- 菜单状态（0-正常 / 1-停用）
- 菜单类型（M 目录/C 菜单/F 按钮）

**列表字段：**
- 菜单名称、图标、显示顺序
- 路由地址、组件路径、权限标识
- 类型、显示状态、状态
- 创建时间、操作列

**权限标识：** `system:menu:list`

### 2.2 新增菜单

**功能描述：** 创建新的菜单

**必填字段：**
- 上级菜单（树形选择）
- 菜单类型（M 目录/C 菜单/F 按钮）
- 菜单名称
- 显示顺序

**类型相关字段：**

**目录（M）：**
- 路由地址（可选）
- 显示状态
- 状态

**菜单（C）：**
- 路由地址
- 组件路径
- 路由名称（可选）
- 是否外链
- 是否缓存
- 显示状态
- 状态

**按钮（F）：**
- 权限标识（必填）
- 状态

**业务校验：**
1. 校验同级菜单名称是否重复
2. 校验上级菜单不能是自己
3. 校验路由地址/名称是否重复
4. 外链地址格式校验

**权限标识：** `system:menu:add`

### 2.3 修改菜单

**功能描述：** 修改菜单信息

**可修改字段：** 同新增菜单

**业务校验：**
1. 校验同级菜单名称是否重复（排除自身）
2. 校验上级菜单不能是自己
3. 校验路由地址/名称是否重复（排除自身）
4. 外链地址格式校验

**权限标识：** `system:menu:edit`

### 2.4 删除菜单

**功能描述：** 删除菜单

**业务规则：**
1. 检查是否存在子菜单（有则不允许删除）
2. 检查菜单是否已分配给角色（有则不允许删除）

**权限标识：** `system:menu:remove`

## 三、权限设计

### 3.1 权限标识清单

| 权限标识 | 权限名称 | 说明 |
|---------|---------|------|
| `system:menu:list` | 菜单查询 | 查询菜单列表 |
| `system:menu:query` | 菜单详情 | 查询菜单详细信息 |
| `system:menu:add` | 菜单新增 | 新增菜单 |
| `system:menu:edit` | 菜单修改 | 修改菜单信息 |
| `system:menu:remove` | 菜单删除 | 删除菜单 |

### 3.2 菜单权限标识

菜单的 `perms` 字段存储权限字符串，用于前端按钮权限控制：

- 格式：`模块：功能：操作`（如 `system:user:add`）
- 前端使用 `v-hasPermi` 指令控制显示
- 后端使用 `@PreAuthorize` 注解控制访问

## 四、菜单类型说明

### 4.1 目录（M）

- 用于组织菜单结构
- 无组件路径
- 可包含子菜单
- 示例：系统管理、系统监控

### 4.2 菜单（C）

- 实际的功能页面
- 必须有组件路径
- 可包含按钮
- 示例：用户管理、角色管理

### 4.3 按钮（F）

- 页面内的操作按钮
- 必须有父菜单
- 配置权限标识
- 示例：新增、修改、删除

## 九、注意事项

1. **路由命名**：避免使用 Vue Router 保留字
2. **组件路径**：必须与前端实际组件路径一致
3. **权限标识**：按钮必须配置权限标识
4. **缓存配置**：合理配置菜单缓存提升性能
5. **删除检查**：删除前检查是否已分配角色
