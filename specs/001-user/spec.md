# 001-用户管理 - 功能规格

**模块编号：** 001  
**模块名称：** 用户管理 (User Management)  
**所属模块：** 系统管理  
**版本：** 3.9.1  
**最后更新：** 2026-03-12

---

## 一、功能概述

用户管理是系统最核心的基础模块，用于管理系统的所有操作用户。该模块提供用户的完整生命周期管理，包括用户配置、角色分配、岗位管理、状态控制等功能。

### 1.1 核心功能

- **用户 CRUD**：新增、查询、修改、删除系统用户
- **角色分配**：为用户分配一个或多个角色，控制用户权限
- **岗位管理**：为用户配置所属岗位
- **状态控制**：启用/停用用户账号
- **密码管理**：重置用户密码
- **导入导出**：支持 Excel 批量导入导出用户数据
- **数据权限**：基于部门的数据范围控制

### 1.2 业务规则

1. **用户账号唯一性**：用户账号（userName）在全系统必须唯一
2. **手机号码唯一性**：手机号码（phonenumber）在全系统必须唯一
3. **邮箱唯一性**：邮箱（email）在全系统必须唯一
4. **超级管理员保护**：不允许删除或修改超级管理员（userId=1）
5. **数据权限控制**：用户只能操作其数据权限范围内的其他用户
6. **密码加密存储**：用户密码使用 BCrypt 加密存储

## 二、功能详细设计

### 2.1 用户列表查询

**功能描述：** 分页查询系统用户列表，支持多条件筛选

**查询条件：**
- 用户账号（模糊匹配）
- 手机号码（模糊匹配）
- 用户状态（0-正常 / 1-停用）
- 部门 ID（树形选择，支持查询子部门）
- 时间范围（创建时间）

**列表字段：**
- 用户序号、用户账号、用户昵称、部门名称
- 手机号码、邮箱、性别、状态
- 创建时间、最后登录时间、操作列

**权限标识：** `system:user:list`

### 2.2 新增用户

**功能描述：** 创建新的系统用户

**必填字段：**
- 用户账号（2-30 字符，唯一）
- 用户昵称（0-30 字符）
- 所属部门（树形选择）
- 密码（加密存储）

**可选字段：**
- 手机号码（11 位，唯一）
- 邮箱（50 字符内，唯一）
- 性别（0-男 / 1-女 / 2-未知）
- 岗位（多选）
- 角色（多选）
- 备注

**业务校验：**
1. 校验用户账号是否已存在
2. 校验手机号码是否已存在
3. 校验邮箱是否已存在
4. 校验部门数据权限
5. 校验角色数据权限

**权限标识：** `system:user:add`

### 2.3 修改用户

**功能描述：** 修改现有用户信息

**可修改字段：** 同新增用户（用户账号不可修改）

**业务校验：**
1. 校验用户是否允许操作（不能修改超级管理员）
2. 校验用户数据权限
3. 校验部门数据权限
4. 校验角色数据权限
5. 校验用户账号、手机号、邮箱唯一性（排除自身）

**权限标识：** `system:user:edit`

### 2.4 删除用户

**功能描述：** 删除一个或多个用户

**业务规则：**
1. 不允许删除当前登录用户自己
2. 不允许删除超级管理员
3. 检查用户数据权限
4. 级联删除用户与角色、岗位的关联关系

**权限标识：** `system:user:remove`

### 2.5 重置密码

**功能描述：** 管理员重置用户密码

**业务规则：**
1. 不允许重置超级管理员密码
2. 检查用户数据权限
3. 密码加密存储

**权限标识：** `system:user:resetPwd`

### 2.6 状态修改

**功能描述：** 启用或停用用户账号

**状态值：**
- `0` - 正常（可登录）
- `1` - 停用（禁止登录）

**业务规则：**
1. 不允许停用超级管理员
2. 检查用户数据权限

**权限标识：** `system:user:edit`

### 2.7 授权角色

**功能描述：** 为用户分配角色

**业务规则：**
1. 检查用户数据权限
2. 检查角色数据权限
3. 清空原有角色关联，重新建立关联

**权限标识：** `system:user:edit`

### 2.8 导入用户

**功能描述：** 从 Excel 文件批量导入用户数据

**导入模板字段：**
- 部门编号、登录名称、用户名称
- 邮箱、手机号码、性别
- 岗位编号、角色编号、备注

**导入模式：**
- **新增模式**：仅导入不存在的用户
- **更新模式**：已存在用户则更新数据

**业务规则：**
1. 校验数据格式（必填字段、格式校验）
2. 校验账号、手机号、邮箱唯一性
3. 校验部门数据权限
4. 初始密码使用系统配置 `sys.user.initPassword`

**权限标识：** `system:user:import`

### 2.9 导出用户

**功能描述：** 导出用户列表为 Excel 文件

**导出字段：** 同列表显示字段

**权限标识：** `system:user:export`

## 三、权限设计

### 3.1 权限标识清单

| 权限标识 | 权限名称 | 说明 |
|---------|---------|------|
| `system:user:list` | 用户查询 | 查询用户列表 |
| `system:user:query` | 用户详情 | 查询用户详细信息 |
| `system:user:add` | 用户新增 | 新增用户 |
| `system:user:edit` | 用户修改 | 修改用户信息、状态、授权 |
| `system:user:remove` | 用户删除 | 删除用户 |
| `system:user:resetPwd` | 重置密码 | 重置用户密码 |
| `system:user:import` | 导入用户 | 批量导入用户 |
| `system:user:export` | 导出用户 | 导出用户数据 |

### 3.2 数据权限

用户管理模块支持基于部门的数据权限控制：

1. **全部数据权限**：可查看所有部门用户
2. **自定义数据权限**：可查看指定部门用户
3. **本部门数据权限**：仅查看本部门用户
4. **本部门及以下数据权限**：查看本部门及子部门用户
5. **仅本人数据权限**：仅查看自己

数据权限通过 `@DataScope` 注解实现，自动过滤 SQL 查询结果。

## 七、关联模块

| 关联模块 | 关联关系 | 说明 |
|---------|---------|------|
| 角色管理 | 多对多 | 用户通过中间表 `sys_user_role` 关联角色 |

| 菜单管理 | 间接关联 | 通过角色关联菜单权限 |

## 八、注意事项

1. **超级管理员保护**：userId=1 的用户为超级管理员，不允许删除、停用、修改权限
2. **密码安全**：密码使用 BCrypt 加密，前端传输建议使用 HTTPS
3. **数据一致性**：删除用户时需级联删除角色、岗位关联
4. **导入性能**：大批量导入时注意事务控制和内存占用
5. **缓存更新**：用户信息修改后需清除相关缓存
