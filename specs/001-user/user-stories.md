## 1. 用户管理功能

### US-001-001 用户列表查询

**作为** 系统管理员  
**我想要** 查看用户列表  
**以便于** 了解系统中所有用户的基本信息

**验收标准**：
- [ ] 可以查看用户列表，包含用户账号、昵称、部门、手机号、状态等信息
- [ ] 支持分页展示
- [ ] 支持按部门筛选用户
- [ ] 支持按用户名、手机号模糊搜索
- [ ] 支持按状态筛选
- [ ] 支持按创建时间范围筛选
- [ ] 只能看到数据权限范围内的用户

**优先级**：高  
**故事点**：3

---

### US-001-002 用户新增

**作为** 系统管理员  
**我想要** 新增用户  
**以便于** 为新员工创建系统账号

**验收标准**：
- [ ] 可以填写用户基本信息（账号、昵称、部门、手机号、邮箱等）
- [ ] 可以设置初始密码
- [ ] 可以为用户分配角色
- [ ] 可以为用户分配岗位
- [ ] 账号不能重复
- [ ] 手机号不能重复（非空时）
- [ ] 邮箱不能重复（非空时）
- [ ] 密码加密存储

**优先级**：高  
**故事点**：5

---

### US-001-003 用户修改

**作为** 系统管理员  
**我想要** 修改用户信息  
**以便于** 更新用户的个人信息或调整权限

**验收标准**：
- [ ] 可以修改用户昵称、部门、手机号、邮箱等信息
- [ ] 可以修改用户角色
- [ ] 可以修改用户岗位
- [ ] 不能修改用户账号
- [ ] 不能修改管理员用户（userId=1）
- [ ] 需要有该用户的数据权限

**优先级**：高  
**故事点**：3

---

### US-001-004 用户删除

**作为** 系统管理员  
**我想要** 删除用户  
**以便于** 移除离职员工的系统账号

**验收标准**：
- [ ] 可以批量删除用户
- [ ] 不能删除当前登录用户
- [ ] 不能删除管理员用户（userId=1）
- [ ] 删除是逻辑删除（设置del_flag=2）
- [ ] 需要有该用户的数据权限

**优先级**：中  
**故事点**：2

---

### US-001-005 用户导出

**作为** 系统管理员  
**我想要** 导出用户列表  
**以便于** 在Excel中查看或存档用户信息

**验收标准**：
- [ ] 可以导出用户列表为Excel文件
- [ ] 导出内容包含用户基本信息、部门、状态等
- [ ] 支持按筛选条件导出

**优先级**：低  
**故事点**：2

---

### US-001-006 用户导入

**作为** 系统管理员  
**我想要** 批量导入用户  
**以便于** 快速创建大量用户账号

**验收标准**：
- [ ] 可以下载导入模板
- [ ] 可以上传Excel文件导入用户
- [ ] 可以选择是否更新已存在的用户
- [ ] 导入后显示导入结果
- [ ] 导入失败时显示具体错误信息

**优先级**：低  
**故事点**：5

---

### US-001-007 重置密码

**作为** 系统管理员  
**我想要** 重置用户密码  
**以便于** 帮助忘记密码的用户恢复账号访问

**验收标准**：
- [ ] 可以为用户重置密码
- [ ] 新密码加密存储
- [ ] 不能重置管理员密码
- [ ] 需要有该用户的数据权限

**优先级**：高  
**故事点**：2

---

### US-001-008 修改用户状态

**作为** 系统管理员  
**我想要** 启用或停用用户  
**以便于** 控制用户对系统的访问

**验收标准**：
- [ ] 可以快速切换用户状态（启用/停用）
- [ ] 停用的用户无法登录系统
- [ ] 不能停用管理员用户
- [ ] 需要有该用户的数据权限

**优先级**：中  
**故事点**：2

---

### US-001-009 用户授权角色

**作为** 系统管理员  
**我想要** 为用户分配角色  
**以便于** 控制用户的功能权限和数据权限

**验收标准**：
- [ ] 可以查看用户当前角色
- [ ] 可以为用户分配多个角色
- [ ] 可以为用户取消角色
- [ ] 不能修改管理员用户的角色
- [ ] 需要有角色数据权限

**优先级**：高  
**故事点**：3

## 2. 个人中心功能

### US-001-010 查看个人信息

**作为** 系统用户  
**我想要** 查看我的个人信息  
**以便于** 确认我的账号信息是否正确

**验收标准**：
- [ ] 可以查看用户名、昵称、部门、手机号、邮箱等信息
- [ ] 可以查看所属角色组
- [ ] 可以查看所属岗位组

**优先级**：高  
**故事点**：1

---

### US-001-011 修改个人信息

**作为** 系统用户  
**我想要** 修改我的个人信息  
**以便于** 更新我的联系方式等个人资料

**验收标准**：
- [ ] 可以修改昵称
- [ ] 可以修改手机号
- [ ] 可以修改邮箱
- [ ] 可以修改性别
- [ ] 手机号不能与他人重复
- [ ] 邮箱不能与他人重复

**优先级**：高  
**故事点**：2

---

### US-001-012 修改密码

**作为** 系统用户  
**我想要** 修改我的密码  
**以便于** 保护我的账号安全

**验收标准**：
- [ ] 需要输入原密码验证身份
- [ ] 需要输入新密码
- [ ] 新密码不能与原密码相同
- [ ] 修改成功后更新Token
- [ ] 密码加密存储

**优先级**：高  
**故事点**：2

---

### US-001-013 上传头像

**作为** 系统用户  
**我想要** 上传我的头像  
**以便于** 个性化我的账号

**验收标准**：
- [ ] 可以上传图片文件
- [ ] 支持常见的图片格式（png、jpg、jpeg、gif）
- [ ] 上传成功后显示新头像
- [ ] 自动删除旧头像文件

**故事点**：2

## 3. 用户注册功能

### US-001-014 用户注册

**作为** 新用户  
**我想要** 注册账号  
**以便于** 使用系统功能

**验收标准**：
- [ ] 系统开启注册功能时可以注册
- [ ] 需要填写用户名和密码
- [ ] 可能需要验证码
- [ ] 用户名不能重复
- [ ] 注册成功后自动登录或跳转登录页

**优先级**：中  
**故事点**：3

---

## 4. 数据权限场景

### US-001-015 数据权限控制

**作为** 有数据权限限制的管理员  
**我想要** 只能看到我权限范围内的用户  
**以便于** 保证数据安全

**验收标准**：
- [ ] 全部数据权限：可以查看所有用户
- [ ] 本部门数据权限：只能查看本部门用户
- [ ] 本部门及以下数据权限：可以查看本部门及子部门用户
- [ ] 仅本人数据权限：只能查看自己
- [ ] 自定义数据权限：查看指定部门用户

**优先级**：高  
**故事点**：5
