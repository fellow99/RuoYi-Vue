# 001-用户管理 - 测试用例

**模块编号：** 001  
**模块名称：** 用户管理  
**版本：** 3.9.1  
**最后更新：** 2026-05-04

---

## 一、测试概述

### 1.1 测试范围

本测试用例覆盖用户管理模块的全部功能，包括用户列表查询、用户新增/修改/删除、重置密码、状态管理、角色授权、导入导出、个人中心（查看个人信息、修改个人信息、修改密码、上传头像）、用户注册以及数据权限控制。测试范围涵盖系统管理员和普通用户两种角色的操作场景。

### 1.2 测试类型

| 测试类型 | 占比 | 说明 |
|---------|------|------|
| 功能测试 | 55% | 核心CRUD及业务逻辑 |
| 界面测试 | 15% | 页面布局、交互 |
| 权限测试 | 15% | 按钮权限、数据权限 |
| 异常测试 | 15% | 边界条件、异常处理 |

### 1.3 测试环境

- 浏览器：Chrome 90+, Firefox 88+
- 分辨率：1920×1080 / 1366×768
- 用户角色：管理员、普通用户
