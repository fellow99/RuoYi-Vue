# 014-cache - 缓存监控模块规格

## 概述

缓存监控模块提供对 Redis 缓存系统的全面监控能力，包括缓存运行状态、内存使用、命令统计以及缓存内容的查看和管理功能。

## 用户故事

### US-001 查看缓存运行状态
**作为** 系统管理员  
**我想要** 查看 Redis 缓存的基本运行信息  
**以便于** 了解缓存服务的健康状态

**验收标准：**
- 能够显示 Redis 版本号
- 能够显示运行模式（单机/集群）
- 能够显示端口号
- 能够显示当前客户端连接数
- 能够显示运行时间（天）
- 能够显示内存使用情况
- 能够显示 CPU 使用情况
- 能够显示 AOF 开启状态
- 能够显示 RDB 备份状态
- 能够显示 Key 总数量
- 能够显示网络入口/出口速率

### US-002 查看命令统计
**作为** 系统管理员  
**我想要** 查看 Redis 命令执行统计  
**以便于** 分析缓存使用模式和性能瓶颈

**验收标准：**
- 以饼图形式展示各命令的执行次数占比
- 显示命令名称（去除 cmdstat_ 前缀）
- 显示命令调用次数
- 支持图表自适应窗口大小

### US-003 查看内存信息
**作为** 系统管理员  
**我想要** 查看缓存内存使用详情  
**以便于** 监控内存消耗和规划容量

**验收标准：**
- 以仪表盘形式展示内存使用情况
- 显示当前使用内存（人类可读格式）
- 显示内存峰值
- 支持图表自适应窗口大小

### US-004 管理缓存列表
**作为** 系统管理员  
**我想要** 查看和管理所有缓存命名空间  
**以便于** 了解系统缓存分布并清理无用缓存

**验收标准：**
- 列出所有预定义的缓存名称
- 显示缓存名称和备注信息
- 支持刷新缓存列表
- 支持清理指定名称的所有缓存
- 点击缓存名称可查看其键名列表

### US-005 管理缓存键名
**作为** 系统管理员  
**我想要** 查看和管理缓存键名  
**以便于** 定位和清理特定缓存数据

**验收标准：**
- 根据选中的缓存名称列出所有匹配的键名
- 支持刷新键名列表
- 支持清理指定键名的缓存
- 点击键名可查看缓存内容

### US-006 查看缓存内容
**作为** 系统管理员  
**我想要** 查看缓存键的具体内容  
**以便于** 验证缓存数据和调试问题

**验收标准：**
- 显示缓存名称
- 显示缓存键名
- 显示缓存内容（支持多行文本）
- 支持刷新缓存内容

### US-007 清理全部缓存
**作为** 系统管理员  
**我想要** 一键清理所有缓存  
**以便于** 在紧急情况下快速重置缓存状态

**验收标准：**
- 提供清理全部缓存的操作按钮
- 执行前应有明确的确认提示
- 清理后显示成功消息

## 功能需求

### FR-001 缓存信息获取
系统必须提供获取 Redis 缓存详细信息的接口，包括：
- Redis INFO 命令返回的所有信息
- 数据库键数量（DBSIZE）
- 命令统计（INFO commandstats）

### FR-002 缓存命名空间管理
系统必须支持以下预定义缓存命名空间：
| 缓存 Key | 说明 |
|---------|------|
| login_tokens: | 用户信息 |
| sys_config: | 配置信息 |
| sys_dict: | 数据字典 |
| captcha_codes: | 验证码 |
| repeat_submit: | 防重提交 |
| rate_limit: | 限流处理 |
| pwd_err_cnt: | 密码错误次数 |

### FR-003 缓存键名查询
系统必须支持根据缓存名称前缀查询所有匹配的键名，返回有序集合。

### FR-004 缓存内容查询
系统必须支持根据缓存名称和键名查询具体的缓存值。

### FR-005 缓存清理
系统必须支持三种清理操作：
1. 按缓存名称清理（删除所有匹配前缀的键）
2. 按缓存键名清理（删除指定键）
3. 清理全部缓存（删除所有键）

### FR-006 权限控制
所有缓存监控操作必须受权限控制，需要 `monitor:cache:list` 权限。

## 数据模型

### SysCache
缓存信息实体类。

**属性：**
- `cacheName` (String): 缓存名称
- `cacheKey` (String): 缓存键名
- `cacheValue` (String): 缓存内容
- `remark` (String): 备注说明

### RedisInfo
Redis 服务器信息（从 Redis INFO 命令获取）。

**关键属性：**
- `redis_version`: Redis 版本
- `redis_mode`: 运行模式（standalone/cluster）
- `tcp_port`: 端口号
- `connected_clients`: 客户端连接数
- `uptime_in_days`: 运行天数
- `used_memory_human`: 使用内存（人类可读）
- `used_cpu_user_children`: CPU 使用率
- `maxmemory_human`: 最大内存配置
- `aof_enabled`: AOF 是否开启
- `rdb_last_bgsave_status`: RDB 备份状态
- `instantaneous_input_kbps`: 网络入口速率
- `instantaneous_output_kbps`: 网络出口速率

### CommandStat
命令统计信息。

**属性：**
- `name`: 命令名称
- `value`: 调用次数

## 关键实体

- **RedisTemplate**: Spring Data Redis 模板，用于执行 Redis 命令
- **SysCache**: 缓存信息传输对象
- **Properties**: Redis INFO 命令返回值

## 成功标准

### 性能指标
- 缓存信息加载时间 < 2 秒
- 键名列表加载时间 < 3 秒
- 缓存内容查询响应时间 < 1 秒

### 可用性指标
- 缓存监控页面可用性 ≥ 99%
- 支持并发查看操作

### 安全指标
- 所有操作必须经过权限验证
- 清理操作应有日志记录

## 假设

1. 系统已部署 Redis 服务且可正常连接
2. RedisTemplate 已正确配置并注入
3. 用户具有 Redis 访问权限
4. 缓存键名遵循预定义的命名规范

## 依赖

- Spring Data Redis
- Redis 服务器
- Vue.js + Element UI（前端）
- ECharts（图表库）

## 约束

1. 缓存清理操作不可逆，需谨慎使用
2. 大量键名查询可能影响 Redis 性能
3. 某些 Redis 命令可能被禁用或限制
4. 集群模式下部分命令行为可能不同
