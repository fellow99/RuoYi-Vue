# 014-cache - 前端页面

## 页面列表

| 页面名称 | 路由 | 文件路径 | 功能描述 |
|---------|------|---------|---------|
| 缓存监控 | /monitor/cache | views/monitor/cache/index.vue | 查看 Redis 运行状态和统计信息 |
| 缓存列表 | /monitor/cache/list | views/monitor/cache/list.vue | 管理缓存命名空间和键名 |

## 页面详细设计

### 1. 缓存监控页面 (index.vue)

**功能：** 展示 Redis 缓存的整体运行状态和统计信息。

**布局结构：**
```
┌────────────────────────────────────────────┐
│  基本信息卡片 (24 列)                        │
│  ┌──────────────────────────────────────┐  │
│  │ Redis 版本 | 运行模式 | 端口 | 客户端数 │  │
│  │ 运行时间 | 使用内存 | CPU | 内存配置   │  │
│  │ AOF 状态 | RDB 状态 | Key 数 | 网络 IO  │  │
│  └──────────────────────────────────────┘  │
├──────────────────┬─────────────────────────┤
│  命令统计 (12 列)   │   内存信息 (12 列)        │
│  ┌────────────┐  │  ┌─────────────────┐   │
│  │            │  │  │                 │   │
│  │  饼图      │  │  │   仪表盘        │   │
│  │            │  │  │                 │   │
│  └────────────┘  │  └─────────────────┘   │
└──────────────────┴─────────────────────────┘
```

**数据流：**
```
created()
  ↓
getList()
  ↓
getCache() API
  ↓
更新 cache 数据
  ↓
初始化 ECharts 图表
  ↓
渲染完成
```

**图表配置：**

1. **命令统计饼图**
   - 类型：pie
   - 玫瑰图模式：radius
   - 半径：[15, 95]
   - 中心位置：["50%", "38%"]
   - 动画时长：1000ms

2. **内存信息仪表盘**
   - 类型：gauge
   - 最小值：0
   - 最大值：1000
   - 显示格式：人类可读（MB/GB）

**交互功能：**
- 窗口大小自适应（resize 事件）
- 加载状态提示
- 数据实时刷新

**技术栈：**
- Vue 2.x
- Element UI
- ECharts 5.x

### 2. 缓存列表页面 (list.vue)

**功能：** 管理缓存命名空间、键名和查看缓存内容。

**布局结构：**
```
┌────────────┬────────────┬─────────────────────┐
│ 缓存列表    │ 键名列表    │ 缓存内容             │
│ (8 列)      │ (8 列)      │ (8 列)               │
│ ┌────────┐ │ ┌────────┐ │ ┌─────────────────┐ │
│ │ 名称   │ │ │ 键名   │ │ │ 缓存名称：       │ │
│ │ 备注   │ │ │        │ │ │ 缓存键名：       │ │
│ │ [删除] │ │ │ [删除] │ │ │ 缓存内容：       │ │
│ │        │ │ │        │ │ │ [文本域]        │ │
│ └────────┘ │ └────────┘ │ └─────────────────┘ │
└────────────┴────────────┴─────────────────────┘
```

**数据流：**
```
created()
  ↓
getCacheNames()
  ↓
更新 cacheNames 列表
  ↓
用户点击缓存名称
  ↓
getCacheKeys(cacheName)
  ↓
更新 cacheKeys 列表
  ↓
用户点击键名
  ↓
getCacheValue(cacheName, cacheKey)
  ↓
更新 cacheForm 表单
```

**表格配置：**

1. **缓存列表表格**
   - 列：序号、缓存名称、备注、操作
   - 行点击：加载对应键名列表
   - 删除按钮：清理该命名空间所有缓存
   - 刷新按钮：重新加载缓存列表

2. **键名列表表格**
   - 列：序号、缓存键名、操作
   - 行点击：查看缓存内容
   - 删除按钮：清理该键名缓存
   - 刷新按钮：重新加载键名列表

3. **缓存内容表单**
   - 字段：缓存名称、缓存键名、缓存内容
   - 只读模式
   - 清理全部按钮

**交互功能：**

1. **级联选择**
   - 选择缓存名称 → 加载键名列表
   - 选择键名 → 加载缓存内容

2. **刷新操作**
   - 刷新缓存列表
   - 刷新键名列表
   - 刷新缓存内容

3. **清理操作**
   - 清理指定名称缓存
   - 清理指定键名缓存
   - 清理全部缓存

**样式特点：**
- 固定高度：`calc(100vh - 125px)`
- 表格高度自适应
- 卡片式布局
- 图标前缀

**消息提示：**
- 刷新成功提示
- 清理成功提示
- 加载状态提示

### 断点配置
- 大屏（≥1200px）：三列布局
- 中屏（768-1199px）：两列布局

## 生命周期

### index.vue
```
created()
  → getList()
  → openLoading()
  → 获取数据
  → 初始化图表
  → closeLoading()
mounted()
  → 监听窗口 resize
beforeDestroy()
  → 移除 resize 监听
```

### list.vue
```
created()
  → getCacheNames()
  → 加载缓存列表
methods
  → getCacheNames()
  → getCacheKeys()
  → handleCacheValue()
```

## 权限控制

- 页面访问：需要 `monitor:cache:list` 权限
- 操作权限：所有操作共用同一权限标识
- 按钮显示：权限不足时隐藏操作按钮

## 性能优化

1. **图表优化**
   - 使用 echarts.init 缓存实例
   - resize 时复用实例
   - 设置动画时长优化渲染

2. **数据优化**
   - 使用 TreeSet 排序键名
   - 分页加载大量数据
   - 缓存常用查询结果

3. **交互优化**
   - 加载状态提示
   - 操作成功反馈
   - 错误处理友好提示
