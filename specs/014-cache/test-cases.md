# 014-缓存监控 - 测试用例

**模块编号：** 014  
**模块名称：** 缓存监控  
**版本：** 3.9.1  
**最后更新：** 2026-05-04

---

## 一、测试概述

### 1.1 测试范围
本模块测试范围包括 Redis 缓存运行状态展示（基本信息、命令统计饼图、内存信息仪表盘）、缓存命名空间列表管理、缓存键名列表查看、缓存内容查看、缓存清理操作（按名称清理、按键名清理、清理全部）以及权限控制。涉及前端页面包括缓存监控首页（index.vue）和缓存列表管理页（list.vue）。

### 1.2 测试类型
| 测试类型 | 占比 | 说明 |
|---------|------|------|
| 功能测试 | 45% | 缓存信息展示与缓存管理操作 |
| 界面测试 | 20% | ECharts图表、三栏布局、表格交互 |
| 权限测试 | 10% | 菜单与页面访问控制 |
| 异常测试 | 25% | Redis连接异常、空数据、并发清理 |

### 1.3 测试环境
- 浏览器：Chrome 90+, Firefox 88+
- 分辨率：1920×1080 / 1366×768
- 用户角色：系统管理员、普通用户
- 前置条件：Redis服务正常运行

| 属性 | 值 |
|------|-----|
| 用例编号 | TC-014-001 |
| 用例名称 | 查看Redis缓存基本信息 |
| 所属模块 | 缓存监控 |
| 优先级 | 高 |
| 前置条件 | 1. 已登录管理员账号 2. Redis服务正常运行 |
| 关联用户故事 | US-014-001 |

**测试步骤**：

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1 | 导航到"系统监控 > 缓存监控"菜单 | 页面加载，显示loading提示"正在加载缓存监控数据，请稍候！" |
| 2 | 等待数据加载完成 | loading消失，显示"基本信息"卡片 |
| 3 | 检查基本信息卡片内容 | 展示Redis版本、运行模式（单机/集群）、端口、客户端数 |
| 4 | 检查第二行 | 显示运行时间(天)、使用内存、使用CPU、内存配置 |
| 5 | 检查第三行 | 显示AOF是否开启（是/否）、RDB是否成功、Key数量、网络入口/出口速率(kps) |
| 6 | 验证数据格式 | CPU保留2位小数，内存以人类可读格式显示 |

**测试数据**：
| 字段 | 值 | 说明 |
|------|----|------|
| redis_version | 6.2.6 | 典型版本号 |
| redis_mode | standalone | 单机模式 |
| connected_clients | >0 | 至少1个连接 |
| uptime_in_days | 数值 | 运行天数 |
| aof_enabled | 0 或 1 | AOF状态 |
