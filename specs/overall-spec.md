## 一、系统概述

### 1.1 系统定位

RuoYi-Vue 是一套基于 SpringBoot + Vue 前后端分离的 Java 快速开发框架，提供完善的权限管理、系统监控、代码生成等功能，帮助企业快速搭建企业级后台管理系统。

### 1.2 目标用户

- **企业管理员：** 系统配置、用户管理、权限分配
- **普通用户：** 日常业务操作、信息查询
- **开发人员：** 基于框架进行二次开发

### 1.3 核心价值

1. **快速开发：** 提供通用功能模块，减少重复开发
2. **权限完善：** 细粒度权限控制，支持数据权限
3. **易于扩展：** 模块化设计，支持功能扩展
4. **开箱即用：** 内置常用功能，配置即可使用

### 1.4 系统特点

- 前后端分离架构
- RESTful API 设计
- JWT 无状态认证
- 完善的权限管理
- 丰富的系统监控
- 代码生成提效

## 二、核心功能列表

系统共包含 **18 个内置功能模块**，分为三大类别。

### 2.1 系统管理模块（9 个功能）

| 序号 | 功能名称 | 功能描述 | 优先级 |
|------|----------|----------|--------|
| 1 | 用户管理 | 系统用户配置，包含用户 CRUD、导入导出、角色分配、密码重置 | P0 |
| 2 | 部门管理 | 配置系统组织机构（公司、部门、小组），树形结构，支持数据权限 | P1 |
| 3 | 岗位管理 | 配置系统用户所属职务，岗位与用户关联 | P2 |
| 4 | 菜单管理 | 配置系统菜单、操作权限、按钮权限标识，支持菜单树 | P0 |
| 5 | 角色管理 | 角色菜单权限分配、数据范围权限划分、用户分配 | P0 |
| 6 | 字典管理 | 维护系统常用固定数据，字典类型与字典数据管理 | P1 |
| 7 | 参数管理 | 动态配置系统常用参数，支持缓存 | P2 |
| 8 | 通知公告 | 系统通知公告信息发布维护 | P2 |
| 9 | 个人中心 | 用户个人信息管理、密码修改、头像上传 | P2 |

### 2.2 系统监控模块（7 个功能）

| 序号 | 功能名称 | 功能描述 | 优先级 |
|------|----------|----------|--------|
| 10 | 操作日志 | 系统正常操作日志记录和查询，异常信息日志记录 | P1 |
| 11 | 登录日志 | 系统登录日志记录查询，包含登录异常、账户解锁 | P1 |
| 12 | 在线用户 | 当前系统中活跃用户状态监控，支持强退 | P2 |
| 13 | 定时任务 | 在线任务调度管理（添加、修改、删除），执行结果日志 | P2 |
| 14 | 缓存监控 | 系统缓存信息查询，命令统计，缓存清理 | P3 |
| 15 | 服务器监控 | 监视系统 CPU、内存、磁盘、JVM 等信息 | P3 |
| 16 | 连接池监视 | 数据库连接池状态监控，SQL 分析，性能瓶颈分析 | P3 |

### 2.3 系统工具模块（3 个功能）

| 序号 | 功能名称 | 功能描述 | 优先级 |
|------|----------|----------|--------|
| 17 | 代码生成 | 前后端代码生成（java、html、xml、sql），支持 CRUD 下载 | P1 |
| 18 | 系统接口 | 根据业务代码自动生成 API 接口文档（Swagger） | P3 |
| 19 | 在线构建器 | 拖动表单元素生成 HTML 代码，表单设计器 | P3 |

## 三、用户角色定义

### 3.1 角色分类

系统预置以下角色，支持自定义扩展。

| 角色名称 | 角色标识 | 角色描述 | 权限范围 |
|----------|----------|----------|----------|
| 超级管理员 | admin | 系统最高权限角色 | 所有权限 |
| 普通角色 | common | 普通用户角色 | 部分权限 |
| 自定义角色 | - | 用户自定义角色 | 按需分配 |

### 3.2 角色权限

#### 超级管理员 (admin)

- **用户管理：** 全部权限（增删改查、导入导出、角色分配）
- **角色管理：** 全部权限
- **菜单管理：** 全部权限
- **部门管理：** 全部权限
- **岗位管理：** 全部权限
- **字典管理：** 全部权限
- **参数管理：** 全部权限
- **通知公告：** 全部权限
- **系统监控：** 全部权限
- **系统工具：** 全部权限

#### 普通角色 (common)

- **个人中心：** 查看和修改个人信息
- **通知公告：** 查看权限
- **其他权限：** 按需分配

### 3.3 数据权限

系统支持基于角色的数据范围权限：

| 数据范围 | 说明 | 适用场景 |
|----------|------|----------|
| 全部数据权限 | 可查看所有数据 | 系统管理员 |
| 自定数据权限 | 可查看指定部门数据 | 部门经理 |
| 本部门数据权限 | 可查看本部门数据 | 部门主管 |
| 本部门及以下数据权限 | 可查看本部门及下级部门数据 | 区域经理 |
| 仅本人数据权限 | 仅可查看自己创建的数据 | 普通员工 |

## 四、功能边界

### 4.1 系统范围内

#### 包含的功能

1. **用户与权限管理**
   - 用户 CRUD 操作
   - 角色权限分配
   - 菜单权限控制
   - 数据权限控制

2. **系统监控**
   - 操作日志记录
   - 登录日志记录
   - 在线用户监控
   - 服务器状态监控
   - 缓存状态监控
   - 数据库连接池监控

3. **系统工具**
   - 代码生成
   - 接口文档
   - 表单构建

4. **基础服务**
   - 认证授权
   - 文件上传下载
   - 字典数据
   - 参数配置
   - 通知公告

#### 不包含的功能

1. **具体业务功能**
   - 系统不包含具体业务逻辑
   - 需要基于框架二次开发

2. **工作流引擎**
   - 不包含 BPMN 工作流
   - 可集成 Activiti/Flowable

3. **报表系统**
   - 不包含复杂报表功能
   - 可集成 FineReport 等

4. **消息推送**
   - 不包含实时消息推送
   - 可集成 WebSocket

5. **第三方集成**
   - 不包含特定第三方系统集成
   - 提供通用集成方案

### 4.2 与其他系统边界

#### 输入边界

| 输入类型 | 来源 | 处理方式 |
|----------|------|----------|
| 用户操作 | 浏览器 | 前端表单提交 |
| 文件上传 | 浏览器 | 文件上传接口 |
| API 调用 | 外部系统 | RESTful API |

#### 输出边界

| 输出类型 | 目标 | 处理方式 |
|----------|------|----------|
| 页面响应 | 浏览器 | 前端渲染 |
| 文件下载 | 浏览器 | 文件下载接口 |
| API 响应 | 外部系统 | RESTful API |
| 日志数据 | 日志系统 | 日志文件/ELK |

### 4.3 功能依赖

#### 内部依赖

```
用户管理 ←→ 角色管理 ←→ 菜单管理
    ↓           ↓           ↓
部门管理    数据权限    按钮权限
    ↓
岗位管理
```

#### 外部依赖

| 依赖项 | 用途 | 是否必需 |
|--------|------|----------|
| MySQL | 数据存储 | 是 |
| Redis | 缓存、会话 | 是 |
| JDK 17+ | 运行环境 | 是 |
| Nginx | 反向代理 | 否（推荐） |

## 五、功能详细说明

### 5.1 用户管理

#### 功能描述
管理系统用户，包括用户的增删改查、导入导出、角色分配、密码重置等功能。

#### 主要功能点
- 用户列表查询（支持多条件筛选）
- 新增用户（包含基本信息、角色、岗位）
- 修改用户信息
- 删除用户（支持批量删除）
- 用户导入（Excel 导入）
- 用户导出（Excel 导出）
- 重置密码
- 分配角色

#### 数据权限
支持基于部门的数据权限控制。

### 5.2 角色管理

#### 功能描述
管理系统角色，包括角色的增删改查、菜单权限分配、数据权限分配、用户分配等功能。

#### 主要功能点
- 角色列表查询
- 新增角色
- 修改角色
- 删除角色（支持批量删除）
- 分配菜单权限
- 分配数据权限
- 分配用户

#### 数据权限
角色本身的数据权限控制。

### 5.3 菜单管理

#### 功能描述
管理系统菜单，包括菜单的增删改查、权限标识配置、按钮权限配置等功能。

#### 主要功能点
- 菜单列表（树形展示）
- 新增菜单（目录、菜单、按钮）
- 修改菜单
- 删除菜单
- 菜单权限标识配置
- 按钮权限标识配置

#### 菜单类型
- **目录：** 一级导航，如"系统管理"
- **菜单：** 具体页面，如"用户管理"
- **按钮：** 页面内操作按钮，如"新增"、"删除"

### 5.4 部门管理

#### 功能描述
管理系统组织机构，包括部门的增删改查、树形结构展示、数据权限配置等功能。

#### 主要功能点
- 部门列表（树形展示）
- 新增部门
- 修改部门
- 删除部门
- 部门数据权限配置

#### 树形结构
支持无限层级部门树。

### 5.5 操作日志

#### 功能描述
记录系统操作日志，包括操作人、操作时间、操作内容、IP 地址等信息。

#### 主要功能点
- 日志列表查询
- 日志详情查看
- 日志导出
- 日志清理

#### 记录内容
- 操作模块
- 操作类型
- 操作人员
- 操作时间
- 操作 IP
- 操作地点
- 请求参数
- 返回结果

### 5.6 代码生成

#### 功能描述
根据数据库表结构自动生成前后端代码，包括 Entity、Mapper、Service、Controller、Vue 页面等。

#### 主要功能点
- 导入数据库表
- 配置生成信息
- 预览生成代码
- 生成代码下载
- 批量生成

#### 生成内容
- **后端：** Entity、Mapper、Service、Controller
- **前端：** API、Vue 页面
- **SQL：** 菜单 SQL、字典 SQL

## 七、系统约束

### 7.1 技术约束

1. **后端：** JDK 17+、Spring Boot 4.x
2. **前端：** Vue 2.x、Element UI
3. **数据库：** MySQL 8.0+
4. **缓存：** Redis 5.0+

### 7.2 业务约束

1. **用户账号：** 唯一，不可重复
2. **角色标识：** 唯一，不可重复
3. **菜单权限：** 树形结构，父级必须存在
4. **部门结构：** 树形结构，支持无限层级

### 7.3 安全约束

1. **密码策略：** 至少 8 位，包含大小写字母和数字
2. **登录限制：** 连续失败 5 次锁定账户
3. **会话超时：** 30 分钟无操作自动登出
4. **权限验证：** 所有接口必须验证权限
